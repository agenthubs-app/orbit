## 读清单时要保留的边界

1. 按钮不一定请求 API：很多只是切 Tab、展开、预填草稿或跳转。
2. 服务端读取不一定出现在浏览器 fetch 中：活动目录、初始模型等由页面服务直接加载。
3. 出现一个入口，不代表功能已接通。例如导入来源里多个渠道仍是不可用边界，「安排约见」通用弹窗在此基线明确提示服务未配置。
4. AI 预填不等于已经生成；草稿不等于发送；复制链接不等于发出邀请；同桌和签到不等于发生交流；报名不等于审核通过；生成不等于发布。
5. 空态、权限不足、配置缺失、版本冲突、正在处理和失败态，均是设计要覆盖的画面。

源码级路由与可达界面盘点已完成；并非所有登录角色、数据组合及弹窗状态都已经浏览器逐一验收。详见覆盖说明。
