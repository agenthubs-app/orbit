# Sprint AG17 — 用户自己的 Claude、Codex 能读授权的资料、提出修改

## 要实现什么

用户在 Orbit 里授权自己的 Claude 或 Codex 之后，它们能按用户勾选的范围读笔记、待办这类记录，也能提出修改。修改不会直接生效：Orbit 生成一张待确认的卡和一个 24 小时内有效的链接，用户登录 Orbit 打开链接，看清要改什么，自己点确认才执行。

## 做完能看到什么

- 没授权的 Claude、Codex 来读，会被拒绝并被告知去哪里授权。授权时用户逐个领域勾选“只读”或“可以提修改”，它们只看得到被允许用的功能。
- 它们读到的只有授权范围内的内容：没有个人记忆、完整对话、电话邮箱，也没有别人的数据。笔记里夹带的“给 AI 的指令”只当普通文字返回，不会被照做。
- 它们提出修改后拿到编号、链接和到期时间。链接里看不出账号和内容；换别的账号打开什么都看不到；过了 24 小时再打开，页面说明已经失效，要重新提。
- 设置里能看到每个连接：哪个客户端、能读什么、能改什么、上次什么时候用过。点撤销后它马上不能再用，还没确认的修改一并作废，已经确认执行的照旧保留。

## 怎么验收

- 本机测试：用一个模拟的外部客户端，把授权、读取、提修改、确认、过期、撤销完整走一遍。十个检查场景全部通过，每个场景由两个互不相见的 Claude 会话分别评审。
- 页面：确认链接页、授权页和连接管理页，在电脑宽屏和手机窄屏上各看一次，打开时不闪动。
- 真实客户端：与 Claude、Codex 各实际连一次。这一步需要一个外网能访问的地址，超出本机测试环境，要你另外授权，并由你本人在 Claude、Codex 里登录 Orbit、点同意。做完之前，这一项记为未完成。
