# Sprint AG14 — 个人记忆：记住、改正、忘掉，并看得到什么时候用了

## 要实现什么

用户在对话里说“记住……”，Orbit 出一张记忆卡，点了确认才保存；之后只在相关的事情上用它，并在回答开头说明用了哪一条。用户说“这次……”就只这一次不按它来，说“以后……”就改掉它，说“忘掉……”就删掉它。网页和手机的设置页与对话里看到的是同一批条目，别的账号看不到。

## 做完能看到什么

- 说“记住，以后给我推荐活动时优先周末上午”，出一张卡，点确认才保存。“从对话里记住新的”这个开关关着时，这句话只用在这一轮，并告诉用户想长期保存可以怎么做。
- 新开对话问下周有什么活动，回答开头写“按你存的偏好‘周末上午’挑的”。问待办时不拿活动偏好出来，但“回答用日语”这类一直遵守的规矩每次都生效。
- “这次看周四晚上”只影响这一次；“以后改成周末下午”出一张卡，原来的和新的并排列出，点了才改。
- 忘掉之后，新对话、回到旧对话、旧聊天里那句“记住”，都不会让它再出现。
- 设置页分“一直遵守的”和“酌情参考的”两组，有“回答时参考这些”和“从对话里记住新的（会先问你）”两个开关，每条可改、可删、可设到期日。

## 怎么验收

- 测试：记忆按“账号＋工作区”存取；设置页和对话认的是同一个人；换成另一个账号什么都读不到、删不掉；忘掉后回到旧对话也不再用。
- 旧数据：先只读清点，只搬能证明是谁的条目，不按名字或邮箱去合并；本次只在本机测试库上做。
- Agent 用例：记忆区 12 例，加常规和较大账号各 1 例，在同一次完整运行里全部通过，每例由两个互不相见的评审各评一次。
- 真实界面：网页在 1440 和 375 宽各看一次；手机 App 连同一套本机服务，看到的条目与网页一致。
