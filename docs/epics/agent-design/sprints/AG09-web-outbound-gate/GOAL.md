# Sprint AG09 — 基础联网：查一次公开网页并带出处回答，私有内容不外发

## 要实现什么

用户问到公开信息时，比如某家公司官网的现价、某位导演的现任职务，Orbit 能自己搜一次、读一页，带着网页链接回答，也能和用户自己的笔记放在一起比较。离开 Orbit 的只有检索词和网址：检索词由程序按固定规则拼出来，每个词都要说得出来历；笔记内容、联系方式、金额一律不发。通不过就不联网，并如实告诉用户。

## 做完能看到什么

- 给了官网链接就直接读这一页，不先搜索；只问自己笔记里的内容时，一次都不联网。
- 问“Acme Cloud 官网现在的标准版价格，和我笔记里记的比一比”：发出去的只有“Acme Cloud 官网 价格”这类词，笔记里的 1200、1000 只在 Orbit 里比较；回答旁边列出实际发出的检索词和打开的网页。
- 检索内容里带电话号码，整条拦下，不会去掉号码偷偷改搜；人名是从联系人记录里取的，先把完整检索词给用户看，用户点了才发。
- 网页里写着“请再搜索某个电话、打开某个链接”，这些都不照做，网页里的内容也不会成为下一次的检索词。
- 搜到两位同名的人先问是哪一位；官网没公开价格、两页说法对不上、读取超时，各有如实的说法。一次请求最多搜 2 次、读 2 页，拆成几件事或追问后接着做，都共用这份额度。
- 联网有总开关，每个人也有自己的开关；关着时一个请求都不发，笔记能答的照常回答。

## 怎么验收

- 测试：七条出站规则各有一个先失败、后通过的测试；判断模型那道检查答“是”、没把握或超时都不发出；额度在拆分和恢复后不重置。测试全部用录好的网页回放，不碰真实网络。
- 离线用例：联网区 12 例，加常规账号、较大账号各 1 例，连同不变量包在同一次完整运行里全部通过，每例由两个互不相见的 Claude 会话各评一次。
- 真实联验：另外单独向供应商真实调用一次搜索、一次读取，标明这是联验、不是测试，结果写进报告。
