# Sprint AG16 — 定时任务有新结果时，可以选择在浏览器或手机上收到提醒

## 要实现什么

结果仍然一律放进站内收件箱。在这之上，用户可以给某一条定时任务单独打开提醒：这条任务有新结果时，浏览器或手机上弹一条“有新结果，请到 Orbit 查看”。提醒里不写活动名称、时间、地点这类具体内容。没打开提醒的任务只进收件箱。

## 做完能看到什么

- 在“我的定时任务”里或对话里说“这条任务以后在手机上提醒我”，出一张卡，点了才打开；打开的只是这一条，别的任务照旧只进收件箱。
- 浏览器第一次打开提醒时，会先请用户允许通知；用户点了拒绝，或者后来在系统设置里关掉了通知，收件箱里的结果照常完整，任务也不会停。
- 任务历史里分开写两件事：这一期什么时候算完的，提醒有没有送到。提醒第一次没送出去会再送，但不会重新算一遍，收件箱里也不会多出一条。

## 怎么验收

- 测试：只有打开提醒的任务才发；提醒的标题、正文和附带数据里没有任何资料；授权被拒或撤销后收件箱不受影响；重送提醒时不重新读资料、不调模型。
- Agent 用例：推送区 3 例在同一次完整运行里全部通过，每例两次独立评审。测试里不连真实的推送服务，提醒发到本机的模拟端，并标明是模拟。
- 真实送达：另做一次人工检查，用真实的手机和浏览器各收一条提醒；要先得到你的同意，结果单独记录，不和模拟结果混在一起。
- 真实界面：提醒开关和浏览器授权的几种状态，在网页 1440、375 宽和手机 App 上各看一次。
