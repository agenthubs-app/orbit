# Sprint AG11 — 在 Web 和 App 的输入框里用 @ 指定要说的那条记录

## 要实现什么

在 Web 和 App 的对话输入框里，键入 `@` 或点「添加上下文」，就能按名字搜到自己的联系人、笔记、待办、日程、活动和「我参加过的」六类记录，选中后随这句话一起发出。Orbit 按选中的那一条去读，不按名字去猜。选中只是告诉 Orbit「我说的是这一条」，不代表允许改它。

## 做完能看到什么

- 输入框上方出现搜索框，结果按六类分组；同名的记录各带一行能分开的信息，比如公司或日期。可以选多条，选中的显示成小标签，点一下就去掉。
- 两篇都叫「客户访谈」的笔记，选了哪篇就读哪篇；去掉其中一篇的标签再发，Orbit 只看剩下那篇。
- @ 了一条待办说「改一下截止时间」，照样先出确认卡，点了才改；@ 了平台活动要改时间，Orbit 说明改不了。一起选中的几条记录不会因此互相关联，也不会被记成长期记忆。
- 选中的记录后来打不开了，回答里提示重新选，其余有依据的部分照常给出。

## 怎么验收

- 测试：两端选择器的搜索、多选、分类显示和移除；发出的消息里每个引用带类型、编号和它在句子里的位置；去掉后不再带旧引用；服务端每一轮逐条核对这些记录是不是本人能看的。
- Agent 用例：REF 区 6 例和分给本 sprint 的 2 个大账号用例，在一次完整运行里全部通过，每例由两个互不相见的 Claude 会话各评一次；此前通过的用例不退步。
- 真实界面：Web 在桌面 1440 和手机 375 各看一次，App 在模拟器上看一次；同一个账号在两端各发一条带 @ 的消息。

动界面之前，选择器的手机稿和网页稿要先经你批准。
