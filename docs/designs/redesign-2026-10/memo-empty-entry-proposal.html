Task › 笔记：一个空状态，讲清楚用途，入口固定

路由 /app/tasks?tab=memo。不加功能：备忘录种类（面谈 / 自由备忘录）、关联联系人和活动（正文 @ 或关联搜索）、「用于计划的已交流项」都来自现有 MemoWorkspace.tsx；新建沿用现有编辑弹窗（?tab=memo&new=1）。UI 文案用 copy/memo.ts 的 zh 值，空状态说明为新写（替换「记下你注意到的事。」）。示例内容均为虚构。

问题（手机现状截图）

  1. 两个一样的空状态：列表区一张「还没有备忘录 / 记下你注意到的事。」，下面详情区又一张同样文字的大白卡（手机上列表和详情上下叠在一起，详情区没有内容时也照样渲染）。
  2. 没有地方新建：桌面的「添加备忘录」在 Shell 页头右侧；手机页头折叠（phoneFold）后这个按钮跟着消失，整页找不到入口。
  3. 看不出这页干什么：「记下你注意到的事。」没有说能记什么、和人 / 活动 / 计划有什么关系；而搜索框和「全部 0 / 面谈 0 / 自由备忘录 0」在没有内容时只是噪音。

方案

  1. 只有一个空状态：列表为空时详情区不渲染（手机）；834 / 1440 列表 + 详情合成一张空状态卡。
  2. 空状态说清用途（四行事实，按代码能做到的写）：面谈 / 自由备忘录两种；正文 @ 关联联系人或活动；面谈只关联一位联系人时可算进计划。
  3. 入口位置固定：手机 = 搜索框右侧一个黑色「＋」圆钮（有内容时常驻）；空状态时搜索行和分类不出，空状态卡里的「添加备忘录」是唯一入口。834 / 1440 = 页头右侧「添加备忘录」（现有位置），空状态卡里不再放按钮。
  4. 有内容时：手机列表 → 点一行进全屏详情（b8「详情 → 全屏页」）；834 / 1440 左列表、右详情。
  5. 搜索无结果：列表里一行「没有匹配的备忘录」，不出卡片、不出说明。
待定：Tab 叫「笔记」，页内全部叫「备忘录」（添加备忘录 / 搜索备忘录）。建议统一成一个词；本稿先照现有文案画。

对标成熟产品的做法

  1. Apple Notes（iPhone）：新建按钮位置永远不变（右下角写字图标），列表为空时只有一行「无备忘录」，不出第二块空白；点一条进全屏详情。本方案手机「＋」固定在搜索行右侧，同理。
  2. Bear / Notion：第一次打开时空状态说明「这里能放什么」并给唯一一个新建按钮；有内容后新建回到固定位置（Notion 侧栏「+ New page」/ Bear 顶部「✎」）。
  3. Apple Notes / Bear（iPad、Mac）：左列表右详情；没有笔记时右侧不画空详情卡。新建在工具栏（本方案的页头右侧）。
