改了什么

  1. 推翻 W-R17-62 / 64 / 65-390（マッチング / 申込設定 / レポート「PC で編集できます」引导页）：手机上直接看、调整、发布。原因：用户要求只用手机就能办完。
  2. 推翻 W-R17-66-390（受付「タブレットか App で」，决定 A8）：手机浏览器就是签到设备——名字搜索、到着、撤销、当日枠、相机扫码、离线保存都在 390 上做。平板 1024 以上仍是 kiosk 布局，同一个地址。
  3. 改写 W-R17-63-390 参加者：原来只有「承認」、批量和见送留给 PC。补上 待ち / 見送り、长按多选 + 底部操作条、详情、筛选、名簿取り込み，以及空、加载、冲突、部分失败。
  4. 页签栏加回「申込設定」（原 61-390 只有 5 项），6 项横向滚动，被截断的一项渐隐露出一半。概要页底部「申込設定とレポートの詳細は PC で編集できます」删掉。
  5. 页头右上改成 ⋯：共同運営者、基本情報を編集、参加コードを再発行、申込ページを開く、イベントを中止 收进一个底部菜单。
  6. 保留不动：運営センター（60）、建活动（01）；概要保留 61 画板（含マッチング卡里的「公開する」——现有实现没放，按画板补上），只删底部那行「申込設定とレポートの詳細は PC で編集できます」。
  7. 拖拽全部有替代：换桌 = 点人 →「移動先」选桌；题目、选项、议程排序 = 同一个「並べ替え」模式 ↑↓（建活动页的议程也用这个组件）。
  8. 見送り 带内部备注：単条与批量的 見送り 确认里同一个「見送り理由のメモ」（主办方内部，不给对方看）。
  9. マッチング 22 桌也不长：桌卡默认收成一行；状态卡里一行可横滑的桌号 chip，点了跳到那一桌。

手机通用做法

  1. 顶栏和页签随内容滚走，不吸顶、不画底色。
  2. 每页至多一个底部主按钮，固定在 Safari 工具栏上方。
  3. 表格一律改卡片行；宽弹窗改底部抽屉；确认用居中小对话框。

对标与待定

  1. 审核：对标 Luma / Eventbrite Organizer 的手机审核——行尾直接批准，其余决定在详情里；多选照 iOS メール / Gmail：长按进入选择，底部操作条。
  2. 换桌：对标 Trello 手机版「カードを移動」——拖拽换成选目标。
  3. 排序：对标 iOS 设置的「編集」模式，进入后每行出现调整控件。
  4. 申込設定：对标 iOS 设置 / Google フォーム 手机：分组行 + 子页面，自动保存，不放保存按钮。
  5. 受付：对标 Eventbrite Organizer / Peatix 受付 / Luma Check-in：手机就是签到机，名字搜索 + 相机连续扫码，离线先存。
  6. 报告：对标 Shopify / Stripe 手机仪表盘：KPI 2×2，图表纵向全宽。
  7. 页签：对标 App Store / YouTube 手机页签：横向滚动，末项露一半。
