五处界面重做：联系方式 · 补资料 · 对方的联系方式 · 编辑资料 · 编辑联系人

功能和数据不变，只重做界面。栏位、按钮、抽屉、底部面板全部用 kit 现有样式，与「新用户引导三步版」同一套（栏位 48 高、无边框、卡内浅灰底）。界面文案以日语为准，标注里给中文 / 英文。示例人物与公司均为虚构。

改了什么

  1. UR-C 引导 ① 的联系方式　现状：灰底大框里再套紫色提示框，四个白底输入框没有占位符，手机上仍是两栏。
    新做法：去掉框中框，和上面的栏位同一种样式；一行小标题「連絡先 · 1つ以上」+ 一句谁能看；LINE、WeChat 直接给出，メール・電話收在「＋」里（名片读到时自动展开）；手机单列。至少一种的规则不变。
    原画板：三步版 W2 / A2 只画了「名刺から」的メール・電話两栏，没有这一组。
  2. UR-R 迁移账号补资料　现状：页面顶上一张小卡，没说为什么；行业下拉只露 6 行，14 个看不出能滚。
    新做法：与引导 ① 同一版式（左表单、右「相手から見えるあなた」）；顶部一句说明来由和补完去哪；行业在电脑上一次摊开 14 个（两列不滚动），手机和 App 用底部面板。
    原画板：没有。
  3. UR-S 对方的联系方式　现状：只是「名前：值」的纯文本，不能复制、不能直接发邮件或打电话。
    新做法：每行一个联系方式，右侧放能做的事（复制 / メール / 電話）；什么都没有时一行说明。生日不出现（谁都看不到）。只出现在人脉详情和主办方的报名者详情。
    原画板：没有（b13 HM-P6 报名者详情无此段）。
  4. UR-P 编辑资料　现状：手机上大灰「閉じる」、两个输入框占位符都是「会社・役職」、多行框带拖拽角、原生蓝色复选框。
    新做法：标准 ✕ 关闭；会社 / 役職分开两栏；「提供 / 求めていること」改成标签输入（每项一枚，最多 5）；自我介绍带字数；公开范围用 kit 开关。
    原画板：b5 #18–20 / b12 W-R18a-01 没画编辑面板（设计是卡片内直接改、右栏开关），面板是实现时自加的。
  5. UR-E 编辑联系人　现状：手机沿用电脑抽屉的头部（✕ · 标题 · 取消 · 保存挤在一行），标题被挤成竖排；表单两栏。
    新做法：电脑照原画板；手机改成 ✕ + 居中标题一行，「保存」放到底部；表单单列分三组；删除在最下面，先确认。
    原画板：b5 E2 有 App 全屏版和 Web 抽屉版；实现把 Web 抽屉直接搬到了手机上，没照 App 版。

已定与待看

  1. 已定 · 谁能看（你已确认）：生日谁都看不到，包括人脉和主办方；联系方式只给人脉里的人（已完成交换）和你报名活动的主办方，不在人脉里的人（包括同场没交换的参会者）看不到。所有说明句都按这两句写。
  2. 待看 1 · LINE 要不要「LINE で開く」：用 ID 打开 LINE 只对允许「ID で検索」的账号有效，打不开时用户会困惑。本稿只给「コピー」（WeChat 同理没有可靠的打开方式）。建议先不加。
  3. 待看 2 · App 编辑联系人跟不跟：b5 E2 的 App 版右上角是 ✓ 图标保存。本稿手机网页改成底部文字「保存」，更好认。建议 App 同步改（两端一致）；不改则只改手机网页。
