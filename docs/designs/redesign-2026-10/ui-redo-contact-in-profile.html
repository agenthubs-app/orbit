编辑资料里加「連絡先」：已走完引导的老用户在这里补 LINE / 微信 / 邮箱 / 电话

接在 UR-P1–P8 之后，编号 UR-P9 起。现在唯一能填联系方式的地方是新用户引导第①步，走完引导的人没有入口。做法复用 UR-C：同一种栏位、LINE 与 WeChat 直接给出、メール・電話收在「＋」里；在这里是选填。示例人物均为虚构。

改了什么

  1. 新增「連絡先」分组：放在「自己紹介」之后、「公開する項目」之前。小标题 + 一句谁能看 + LINE、WeChat 两栏；メール・電話收在「＋ メール・電話を入れる」里，有值时自动展开。
  2. 选填：不写「1つ以上」，不拦保存。只校验格式（邮箱、电话）。
  3. 「公開する項目」里那行固定的「連絡先 · 人脈と主催者のみ」去掉：谁能看已经写在新分组里，紧挨着要填的栏位；同一件事不说两遍。「公開する項目」只剩三个开关。
  4. 保存成功沿用 UR-P3 的做法：关闭面板，底部提示「保存しました」。
  5. 手机输入框字号 16px（iOS 小于 16px 聚焦时会自动放大页面）。
