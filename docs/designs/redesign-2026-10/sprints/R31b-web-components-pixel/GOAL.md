# Sprint R31b — Web 组件库像素轮

## 要实现什么

用 R31a 做好的逐件对照方法，把 Web 组件库逐件对齐设计稿 kit：修掉已知差异（弹窗缺 380 一档和标题图标块、抽屉的关闭按钮 / 副标题 / 内边距、筛选项、开关、分类方块、标签和键盘提示的字色等），处理旧页面全局 `.btn` 样式漏进新组件的问题，补上 Web 端缺的下划线页签，把主办、计划、活动、搜索页面里的手写件换成组件；R31a 的对照工具一做好就可以和 R31a 同时开工；最后把小雨那边 Web 端所有「待组件库」的画面重比通过。

## 做完能看到什么

- Web 组件展示页里每一个组件都和设计稿规格格逐像素一致（浅色、深色）。
- 计划、加人、活动、主办页面里原来因为组件不对而没过门禁的画面，现在都通过了。
- 新组件放进旧页面里也不会被旧样式带歪。

## 怎么验收

逐件对照全部通过；「待组件库」的 Web 画面重比通过，暂缓清单对应行改成 done；所有已通过的 Web 画面没有退步；两端全量零新增失败；独立复核重跑门禁后，产品负责人看截图拍板。
