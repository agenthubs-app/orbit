# Sprint R26 — 活动：评估、一级页与计划接线

## 要实现什么

做出「这场活动值不值得去」的判断入口。贴一个活动页的网址、拍或传一张海报，也可以贴正文、只填三项，系统就会读出活动的事实，用和计划页同一套固定标准打出 0–100 分。分数分三个角度给出理由：和目标的契合、能见到的人、时间与费用。觉得值得，点「参加予定に追加」就把这场活动加进计划。读不出来的情况（要登录、不是活动页、海报模糊）都有明确的退路。

同时把活动的数据接到计划页上。现在计划页上「会える活動」、概要的推荐活动、右栏「今日のチャンス」里的活动都是空的，R26 做完后它们都会显示真实活动，计划页还在等的 12 个画面也就能重新比对。工作人员代为签到时，也会和本人签到一样给计划记分。

两端的「イベント」一级页换成新样子：「評価 / 参加予定 / 探す」三个页签。本 Sprint 做評価和参加予定，探す页签的内容由 R27 做。

## 做完能看到什么

- App 和 Web 的イベント页有新顶栏和三段页签：
  - 評価页能贴网址、选海报，出「判定中」，再出结果；
  - 结果有总分、三项理由、会えそうな人、气をつける点，以及「参加予定に追加 / 見送る」。
- 要登录的页面、不是活动的页面、看不清的海报，都有对应画面：
  - 要登录：贴正文、截图、手填三项；
  - 不是活动页：列出页里找到的活动；
  - 看不清：逐项补齐，补完后分数可以给出区间。
- 参加予定页签列出我报名或加入计划的活动，首页（R10）能拿到「下一场活动」。
- 计划概要出现推荐活动行，右栏「今日のチャンス」会推荐活动，人物类型详情的「会える活動」表有内容。
- 「参加コード」输入入口；界面上不再把活动报名码叫「招待コード」。

## 怎么验收

用三个真实的公开活动网址（connpass / Peatix / 主办方官网各一个）、一张模糊海报、一个需要登录的会员页走完评估；分数和计划页对同一活动显示的分数一致。工作人员代签后计划分数增加。计划页 12 个待重比画面重新跑门禁。每个画面和设计稿逐像素对照（Web 三种宽度 × 浅 / 深，App 浅 / 深）。两端原有的测试一条都没有变坏。
