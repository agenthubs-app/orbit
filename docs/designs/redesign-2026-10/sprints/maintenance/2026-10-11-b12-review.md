# b12-missing-states.html 风格一致性复核（2026-10-11）

对象：`docs/designs/redesign-2026-10/b12-missing-states.html`（147 块画板 × 浅 / 深 = 294 个画框）
对照：`kit/tokens.css`、`kit/ui.css`、`01-system.html`、`app.html`、`web.html`、`b1`–`b11`
证据目录：`~/orbit-sprint-evidence/redesign/b12-review/`（`b12-NNN.png` = b12 画框序号，`ref-<文件>-NNN.png` = 原稿画框序号）

## 结论：有条件一致

- **颜色**：一致。b12 里所有颜色字面量（#hex / rgb / rgba，含 style 属性）都能在原稿里找到出处；没有新写死的白 / 黑；用到的 `var(--*)` 都在 kit 或 b1 / b11 原稿里有定义。
- **组件**：基本一致。大部分 CSS / JS 是从原稿照抄的；各组自己写的部分都是用 kit 现有零件拼出来的（`.pop` / `.op` / `.seg` / `.err-card` / `.offline` / `.degrade` / `.ng-card` / `.confirm-card` / `.lic.i-*`），没有新的圆角或阴影值，也没有新的图标画法。例外是下面的 M1（1024「次の一手」计数徽章是新画的）。
- **视觉**：抽查的 32 块里，字号层级、间距、卡片底色、按钮、底栏 / 左栏 / 顶栏都和参照画板一致；深色框里没有看不清的文字，也没有浅色残留。
- **条件**：要修掉 **H1**（g5 分数条整条不显示，是样式类名冲突造成的，影响 9 块画板 / 18 个画框），再修 **M1**、**M2**，之后才能当作像素基准用。

## 方法

1. **颜色字面量**：脚本扫描 b12 全文（`<style>` 和 JS 模板里的 style 属性），提取 `#hex`、`rgb()`、`rgba()`、`hsl()`、`white`、`black`，和原稿 15 个 HTML 加 kit 4 个文件里出现过的字面量逐个比对。另外列出 b12 用到的所有 `var(--*)`，检查定义在哪里。
2. **新 CSS 行**：把 b12 第 11–1688 行（全部 `<style>`）逐行规整空白后，在原稿全集里查原文。没查到的有 168 行（多为改名的 keyframes 和各组私有段），逐行人工判断。另外查了 JS 里新写行的 style 属性：radius、shadow、color、background、border 这几类声明值，没有一项不在原稿里。还查了 class 名都有定义（只有 `scrollto` / `wdlg` / `copy` 三个 JS 钩子没有样式定义，属正常）。
3. **深色自动扫描**：对 b12 的全部 294 个画框，逐个元素计算文字和底色的对比度、深色框里亮底大于 0.7 亮度的元素。原稿 b4 / b10 / app / web / b11 / 01-system 也跑了同一脚本，作为基线做差。
4. **视觉抽查**：用 playwright（chrome、DPR 1、`body.no-pins`）按画框序号截图，和「参照」指向的原画板并排看。
5. **画板标题**：用 `compare-redesign.mjs --list` 列出 294 个画框，检查标题前缀，并按工具的 `label.includes(board)` 规则模拟定位命中。

### 查过、没有问题的

- 颜色字面量 36 种，全部有出处：名片纸 `#fff` / `#efe9e1` / `#fbf8f3` 等来自 app / b1 / b3 / b4；相机和锁屏的深色系来自 b11；`--paper` / `--cam` 系来自 b1 / b11。只有 b1 / b11 定义、kit 里没有的变量共 7 个（`--cam` `--cam-2` `--cam-ink` `--paper` `--paper-ink` `--paper-ink-2` `--nx`），都是原样照抄。
- 新写的 CSS 行里，圆角和阴影都是原稿里有的值：22（01-system `.pop`）、34（kit `.sheet`）、18（b4 `.ctxm`）、16（01-system `.offline`）、12 / 14；阴影只用 `--shadow-float`；焦点环 `0 0 0 2px surface, 0 0 0 4px plum-500` 来自 01-system `.ds .focus`；渐变 `135deg, mac-lav → surface 70%` 来自 kit 和 app。
- 图标：`ic()` 用的名字都在 kit.js 里，`lic('alert' | 'trash' | 'wifioff')` 是 kit `ui.css` 的 `.lic.i-*`（01-system 有说明）。JS 新写行里没有 `<svg>` / `<path>`。
- 深色：亮底元素都是有意的反相，包括主按钮 / Toast / 气泡 / logo / home 指示条（`rgb(243,240,246)` = 深色主题下的 ink）。#117 的 `.mcard` 白底是 b11 的名片纸（`--paper`），也是有意的。低对比文字只出现在 `--ink-4`（占位、禁用、旧值删除线），和原稿基线一致；「満点 100」对比度为 1 是脚本把刻线底色当成了文字底色，实际看得清（`b12-249.png`）。
- 画板标题：147 / 147 都以 `W-` / `A-` / `N数字` 开头，编号没有重复，工具都能定位（只有 L2 的两个歧义）。
