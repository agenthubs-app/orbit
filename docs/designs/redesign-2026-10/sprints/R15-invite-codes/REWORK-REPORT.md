## 3. 做了什么

1. **Web 发出方**（`InviteCodeModal`）
   - 版式照 b11 #14：头部是标题 + 副标题 + ✕；QR 150，中心有「O」徽章（纠错改为 H 级，静区 2 模块加 8px 外框）；码 22 / 800；链接框 44 + コピー；有効期限 / 使える人数两格；「相手に届くあなたの情報 [変更]」（P1）；下書き卡带「ていねい ▾」语气菜单（ContextMenu）和两行预览；底部是「Orbit からは送信しません · 無効にする」加「下書きをコピー」。
   - これまでのコード只在两种情况下出现：没有可用的码时；有人「同じ人かも」时（出现一行「確認する」入口）。
   - 删掉了 InviteRailCard（已经没有地方用它）。
2. **Web 接收方**（`InviteLanding`）
   - 页面背景是手机雾面。头部是 appic + Orbit + 一行副标题，按状态换：未登录是「アプリなしで登録できます」，已登录是「すでにアカウントがあります」，完了是「登録が完了しました」或「つながりました」，期限切れ / 満員显示地址。
   - 确认页：共享项先显示成 chip，点「変更」才展开开关；📇 一行；つながる / 今はしない 固定在底部（渐隐）。
   - 完了页去掉对方资料卡和「人脈で見る」，照 #10。
   - 期限切れ页加 🔁 说明卡（照稿）。
   - 正文里按姓称呼邀请人（`inviteCallName`，例如「佐藤さんに見せる情報」）；介绍对方的标题仍用全名。
3. **App 发出方**（`InviteSenderScreen`、`invite-kit.tsx`、`InviteQr`）
   - 共用 kit：`KitXl` / `KitGhost` / `KitGuide`（右上淡紫光晕）/ `KitChip` / `KitLink`。
   - 说明页：🤝 guide、3ステップ等宽三格加箭头、FAQ 三行，「コードをつくる」放在底部固定区。
   - 共有页：QR 卡（196，带 O 徽章和细圈）、三个 64 高的大按钮、两格配额、相手に届く情报卡（P1）、无効にする行。右上 ⋯ 打开「これまでのコード / 使い方を見る」。
   - 下書き sheet：标题 + ✕、语气用组件库 `Segmented`（撑满整行，画板是行内的，见 §5）、草稿框（链接加粗）、三个 60 高的按钮（💬LINE で開く 照稿把 emoji 放进文字里）。
4. **App 接收方**（`InviteLandingScreen`）
   - 没有顶栏，用 b11 的 appic 头部。按 P2，App 里不出现「アプリなしで登録できます」。
   - 确认页：chip 加「変更」，底部固定按钮；完了页、期限切れ页同 Web。
   - 本机开关下，`orbit://i/<码>?design=done` 用只读演示直接打开完了页（`add-design-mock` 的 add-scan）。
5. **App 完了页卡片**：Web 那张是「アプリで続ける · 開く」。App 里人已经在 App 中，同一张卡改成「人脈で見る · 本人入力で、お互いの人脈に入りました · 開く」，点了打开这个人（同 P2 的思路，§4-3）。
6. **P1 接口**

   - 保存后的提示是「相手に届く情報を変更しました」。说明文改成「これからコードを開く人に届く情報が変わります。コードとリンクはそのままです。」

## 4. 画板口径冲突（决定表 §21 / §22；需要改画板的已发主会话）

1. **b11 #14 Web 弹窗缺「相手に届くあなたの情報 [変更]」**。P1 已定：发出方可以直接改。按「已定规则一致」，Web 也要能改，所以加了一张和 b11 #7 `.k-isinfo` 一样的卡。**画板待改**：在两格配额与下書き卡之间加这张卡。
2. **b11 #12 的 📇「佐藤さんはすでにあなたの人脈にいます（名刺 · 9/18）。つながると本人入力に統合されます」**和 S1（DESIGN §10 #7）冲突：浏览器里不猜对方是不是已有的人，统合由所有者事后确认。实现用同一张卡写「つながったあと、同じ人かどうか確認できます。」。**画板待改**。
3. **App 接收方套用的是手机网页画板**：App 里没有 Safari 地址栏，这一块按浏览器外壳处理（同 G09 状态栏）；完了页的 App 卡片按 §3-5 处理。**画板待补**：App 版 #10（卡片文字）。
4. **旧版招待画板作废**（§21-4）：b9 #12–#15、#17、#18、#26，b5 #62–#64，都以 b11 A2 为准。b9 #16 受邀者简短资料**仍有效**：实现目前保留原版式，只换了新头部，还没有按 b9 #16 比对（列为下一步）。
5. QR 码在深色下保持浅底深点，这样相机才读得出（§21-3，App 深色已按 #47 比对通过）。
