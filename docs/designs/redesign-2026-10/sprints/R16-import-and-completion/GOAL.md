# Sprint R16 — 加人：导入与「每天一问」

## 要实现什么

把「一次加很多人」做成和名片同一条路：从手机通讯录、LinkedIn 导出的 CSV、其他 CSV（Eight 等）、参加过的活动里把人导进来，系统先按规则挑出「像工作关系的人」，导入后只让用户看例外（可能重复、读得不确定），其余直接进人脈。

导进来的人信息通常很少。「每天一问」每天最多问一个问题（比如「森さんとは、どこで？」），答一个，那个人的信息就多一项；不想答可以跳过，连续跳过 3 次就不再问这个人。这一问不调用 AI。

## 做完能看到什么

- App「人脈を追加」›その他：連絡先（先说明再请求通讯录权限 → 选人，已预选像工作关系的人 → 整理中 → まとめて確認 → 完成）、LinkedIn（说明怎么导出 → 选 CSV 文件）。
- Web「人脈を追加」›その他：連絡先（vCard 文件）、LinkedIn（CSV / ZIP）、CSV、イベントから，都有列对应确认和まとめて確認。
- 「每天一问」接口可以用了，两端各有一张现成的卡片，Task（乙）和人脈（乙）把它放到自己的页面上即可。
- Web 旧的导入页删掉。

## 怎么验收

用一份 LinkedIn 样例 CSV、一份 vCard、模拟器通讯录走完导入（含重复、要確認、全部加入），人脈里多出的人数和完成页一致；每天一问用种子联系人验证出题、回答后这个人的信息多一项、跳过 3 次不再问、按东京时间换天；和设计稿 b9 A2 / A3 / A7 截图对照；两端原有的测试一条都没有变坏。
