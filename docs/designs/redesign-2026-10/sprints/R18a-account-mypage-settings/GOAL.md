# Sprint R18a — 账户：マイページ与設定

## 要实现什么

把两端的「マイページ」和「設定」按设计稿整屏重写，替换掉旧的个人中心：

1. **マイページ**：App 上一屏看到自己的 Orbit 名刺、资料完成度（公司职位、能提供的、在寻找的、自我介绍 4 项，每项 25%）、提供できること / 求めていること（AI 给的候选可以一个个 ✓ / ✕）、公開プロフィールのプレビュー、受信箱、招待コード、主催したイベント、参加するイベント、設定。Web 上是「設定」页的「プロフィール」一栏：左边名刺和完成度，右边实时显示别人看到的样子，并能选「公開する項目」。
2. **编辑资料与标签**：改名字、公司、职位、业界、自我介绍、所在地，增删提供 / 寻求的标签。样式沿用引导页（b1）的输入框。
3. **設定**：App 一屏里直接切语言和外观，查看相机 / 日历 / 通知权限；进「連携」看 Gmail、Google カレンダー 的连接状态并连接或解除；进「iOrbit が使う情報」改目标、自我介绍、删掉 iOrbit 记住的事，开关「意味検索」（这项功能可用时才显示）。没有真实数据来源的东西（同步记录、浏览次数等）不显示。Web 是左侧子菜单：プロフィール / 連携 / iOrbit が使う情報 / 言語と外観 等。
4. **更新の提案**：和 iOrbit 的对话、活动、联系人里发现的资料变化，以及扫描名片、上传职务经历书读出来的内容，逐项 ✓ 后才写入；两端都有。
5. **整理旧东西**：Web 旧的 iOrbit 设置模块（自动化、执行、反馈）从界面上拿掉，接口保留；Web マイページ页签栏里临时加的「主催」链接换成正式入口；付费方案（ご利用プラン Pro）和 NFC 名刺交換这一期不显示；设计稿上这些行和完成度数字先按本期口径改稿。

通知设置页、登录注册与落地页、数据导出与退会不在本 Sprint：它们的入口行照设计稿显示，点进去先是「準備中」（Web「言語と外観」里的「データを書き出す / アカウントを削除」两个链接在 R18c 之前先隐藏）。

## 做完能看到什么

- App：マイページ、公開プロフィール、编辑资料、标签选择、設定、連携、iOrbit が使う情報、更新の提案，全部是新画面；旧屏文件删除。
- Web：`/app/profile` 和 `/app/settings/…` 是带左侧子菜单的新設定页；`/app/profile/suggestions` 是新的「更新の提案」页；旧的 0918 个人中心和四个 iOrbit 设置模块不再出现。
- 主办入口：两端都从マイページ的「主催したイベント」进運営センター，手机浏览器也能进；临时链接已删。
- 设计稿缺的 Web 1024 / 390 和深色画面先补画（放在 b12 末尾），再按补画验收。

## 怎么验收

用三个演示账号（新用户 25%、普通 50%、完整 100%）在两端走一遍：看完成度和缺的项目 → 接受一个 AI 候选 → 改公司和标签 → 看公開プロフィール变化 → 关掉一个公開する項目 → 切语言和外观（另一处入口同步变化）→ 连接 / 解除一个服务 → 删一条 iOrbit 记住的事 → 关掉意味検索后全局搜索不再走意味検索 → 接受一条更新の提案并看到资料变化 → 从「主催したイベント」进運営センター。

每个有画板的画面在组件库像素轮（R31a / R31b）合入后逐像素对照（Web 1440 / 1024 / 390 × 浅 / 深，App 浅 / 深）。两端原有测试没有新增失败。
