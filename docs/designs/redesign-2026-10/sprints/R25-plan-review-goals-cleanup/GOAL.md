# Sprint R25 — 计划 v2.2：见直、达成、多目标与旧屏清理

## 要实现什么

把计划做成能长期用的东西，并把旧计划界面彻底换掉：

- **方案を見直す**：AI 先标出可能变了的前提，用户改完一次发出，得到只列差分的修正案；每月 3 次（不改也算一次），用完时记录、加分、跳过照常。
- **目標を達成した**：确认后分数定格，完成页回顾，AI 给出两个下一目标候选，选了就走和第一次一样的流程。
- **多目标**：同时 2 个目标，下拉切换；编辑目标时可以只保存，也可以「保存して作り直す」。
- **旧计划**：v1 计划显示为只读的「以前のプラン」，引导用户新建。之后谁都不能再生成旧计划（旧引导和旧接口都改为带到新计划入口）。
- **清理**：删掉 Web `/app/agent/plan`（兼容跳转）、`/app/agent/strategy`、旧计划界面文件，App `contacts/matches`、`contacts/intros`，以及只给它们用的接口；产品里所有指向旧计划地址的链接换成新地址。

## 做完能看到什么

- 概要上的「方案を見直す」「手動で編集」「目標を達成した」都能用；配额条显示「今月あと N 回」，用完时主按钮是「わかりました」，没有付费入口。
- 目标名旁的「▾」能切换、添加、编辑目标；第 3 个目标会说明限制，不弹付费墙。
- 首页、iOrbit、人脉分析、活动跟进里所有「去计划」的链接都直接落到新页面，不再经过兼容跳转。
- 两端代码里找不到旧计划界面和旧需求匹配页。

## 怎么验收

見直し（含用完、不改也计次、已得分不变）、達成 → 下一目标、多目标切换与编辑、以前のプラン 的两端测试与截图对照（b4 A3–A6）；旧屏、旧接口、旧链接为零的检查（含归属表计划行全部处理、三份允许清单里这些文件已移除）；两端全量零新增失败。
