# Sprint R04 — App 组件库

## 要实现什么

按设计稿做出 App 的通用组件库（基础、反馈、AI、控件、状态五类，约 25 个组件），并把 App 里各屏幕自己写的弹窗、弹层、分段控件和旧公用组件全部换成新组件，旧的删除。加入手势、动画、毛玻璃和触感反馈的原生依赖，锁定 React Native 版本。

## 做完能看到什么

- App 里的按钮、卡片、标签、弹层、确认框、Toast、开关、分段、空态、加载、离线提示全部是新设计的样子，到处一致。
- 删除、完成这类可以撤销的操作不再弹确认框，而是出现带「元に戻す」的 Toast。
- 左滑行跟手，底部弹层可以拖，开关和按钮有轻触感。
- 开启「减少动效」后，所有动画只剩淡入。
- 开发包和 TestFlight 里有一个组件展示页，可以逐个看每个组件的各种状态。

## 怎么验收

展示页里每个组件和设计稿画板并排截图（浅色、深色、320 宽、2 倍字号）；渲染测试覆盖对比度、触控区、减少动效；被替换的页面原有测试全部通过；模拟器里实际操作左滑、弹层拖动、Toast 撤销；两端全量零新增失败。
