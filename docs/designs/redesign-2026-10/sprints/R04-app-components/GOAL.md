# Sprint R04 — App 组件库

## 要实现什么

按设计稿做出 App 的通用组件库（基础、反馈、AI、控件、状态五类，约 25 个组件）和组件展示页。会一直保留的基础设施（登录会话、访问边界、离线边界、错误边界）改用新组件。加入手势、动画、毛玻璃和触感反馈的原生依赖，锁定 React Native 版本。

旧屏里的弹窗、分段控件和旧公用组件原样保留。这些屏会在功能 Sprint 里整屏重写并删除（RD-24），到时直接用新组件。门禁保证新代码不能再用旧写法、旧用法只减不增；某个旧组件没人用了就删除。

## 做完能看到什么

- 开发包和 TestFlight 里有一个组件展示页，可以逐个看每个组件的各种状态：浅色、深色、2 倍字号、减少动效。
- 组件的按钮、卡片、标签、弹层、确认框、Toast、开关、分段、空态、加载、离线提示都是新设计的样子。
- 可以撤销的操作用带「元に戻す」的 Toast，不弹确认框。
- 左滑行跟手，底部弹层可以拖，开关和按钮有轻触感；开启「减少动效」后只剩淡入。
- 登录、登出、离线、错误提示这些基础设施画面已经是新组件。

## 怎么验收

展示页里每个组件和设计稿画板并排截图（浅色、深色、320 宽、2 倍字号）；渲染测试覆盖对比度、触控区、减少动效；门禁用注入样例证明能拦住新增旧写法；模拟器里实际操作左滑、弹层拖动、Toast 撤销，走一遍登录 / 登出 / 离线；两端全量零新增失败。
