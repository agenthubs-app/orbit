# Sprint R27 — 活动：从找到活动到会后

## 要实现什么

把参加一场活动的整条路重做，两端都要做，一共五段：

1. **找**：「探す」里优先列出对计划有用的活动，分数和计划页同一套。另有「あなたのコミュニティ」（去过或关注的主办方的新活动）、筛选和搜索。不感兴趣的活动可以说一声，以后少推荐。
2. **看**：活动详情有自己的评估分、议程、主办方情况、参加者里有谁值得见。
3. **报名**：AI 只问 5 个问题，然后生成参加用的资料，可以决定谁能看到；报名后能把活动先放进日历。
4. **当天**：
   - 「会う準備」告诉你还剩多久开始、该带几张名片、要见的几个人各自怎么开口、准备清单；
   - 签到后进入「会場モード」：现在在哪一桌、和谁同桌、接下来推荐见谁，可以交换名片、提议约面谈（只出草稿）；
   - 可以用自己的声音记一句话的备忘，不录现场。
5. **会后**：系统整理今天见了谁、聊到什么，并给每个人提议下一步（跟进日期、感谢信草稿、关联到计划人物类型；这部分要升级现有的会后 AI，需要用户授权，授权前先用规则给出跟进日期）。用户勾选确认后才生效，计划分数随之增加。感谢信只是草稿，由用户自己发送。

## 做完能看到什么

- 两端「イベント › 探す」：コミュニティ、プランに効くイベント（带分数和理由）、全部列表、筛选、搜索、「興味なし」。
- 活动详情、报名（5 问 → 资料 → 申込完了）、取消报名确认。
- 会う準備、会場モード（チェックイン / 現場 / おすすめ / 参加者 / グループ / マップ / アジェンダ / 交換 / 面談を提案 / ひとことメモ）、会後のふりかえり。
- 没登录的人也能看公开活动列表和详情；没报名的人打开会场页会看到「还没报名」并能去报名，而不是出错。
- 两端旧的活动详情、报名和会场页删掉。

## 怎么验收

用演示世界的一场活动（CFO Night Tokyo vol.18 的示例数据）走完一遍：
1. 探す → 详情 → 报名（5 问）→ 申込完了 → 会う準備；
2. 签到（本人签到一次；工作人员代签的界面属主办侧 R17，用现有运营接口触发一次）→ 会場（交换 2 人、提议面谈 1 次、一句话备忘 1 条）；
3. 会後确定 5 人的下一步。

核对：To-do、人脈的「在哪认识」、计划分数的变化和画面上的预览一致。

另外，每个画面和设计稿逐像素对照（Web 三种宽度 × 浅 / 深，App 浅 / 深），两端原有的测试一条都没有变坏。
