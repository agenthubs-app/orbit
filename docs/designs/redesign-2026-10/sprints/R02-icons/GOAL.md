# Sprint R02 — 图标源 + 两端 Icon 组件

## 要实现什么

设计稿的 48 个线性图标和 5 个补充图标导出成一份图标源 `shared/design/icons.json`，两端各有一个 `Icon` 组件。设计稿没有、但旧屏用到的图标按同样风格一次补画齐，并出一份「Ionicons → 新图标」对照表，给功能 Sprint 重写旧屏时直接查用。导航壳的图标换成新图标。

旧屏里的 Ionicons 原样保留：这些屏会在功能 Sprint 里整屏重写并删除（RD-24），到时一起换。门禁保证新代码不能再用 Ionicons、旧用法只减不增；最后一个旧屏删除时移除 Ionicons 依赖。

## 做完能看到什么

- 两端各有一个图标展示页，列出全部图标（含补画的），可以和设计稿并排看。
- App 底栏图标来自新图标源。
- 新写的代码一旦 import Ionicons，测试就会失败。

## 怎么验收

对照表覆盖全部 Ionicons 用法；图标展示页与设计稿并排截图（浅色 / 深色）；门禁用注入样例证明能拦住新增用法；两端全量零新增失败。

完整验收项见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；状态见[登记表](../README.md#骨架登记表)。
