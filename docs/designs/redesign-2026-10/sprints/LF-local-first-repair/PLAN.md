# 本地优先回归修复（LF1–LF6）

日期：2026-10-21。依据：数据逻辑核对报告 https://claude.ai/artifact/7bcubDMaJAews3kUzy5V79 （对比 origin/chat-agent 与 origin/redesign@7b2b2c3b7）。用户批准「做一轮本地优先回归修复，分解成数个 Sprint 后逐一处理」。执行者：Claude 主会话亲自做（不调用 Codex）。分支 `lf-repair`（worktree `/Volumes/ORICO/Dev/worktrees/orbit/lf-repair`），基于 redesign；每个 Sprint 结束：两端 tsc 0、定向测试、两端全量逐名对照基线（`_evidence-main/final-*.log`，本线新增 0）、推送到 redesign。不碰生产、不部署。

原则（沿用 0108–0136 与「只让结果离开数据库」）：本机已同步的数据一律先读本机；本机没有的才在线读，并按账号缓存、限频，不在每次切页时重读；断网显示「截至 X 的内容」而不是错误或空列表；服务器只读用得到的数据、设上限、GET 不写库。

| Sprint | 范围 | 验收 |
| --- | --- | --- |
| **LF1 首页与小组件** | 首页卡片改读本机：人脉卡（联系人域算总数/本月新增/最近 4 人）、下一场活动（已报名活动域）、笔记卡（笔记域）、日程/待办（已有页面副本 + 本机）、秘书卡（通知域按秘书来源在本机筛选）；本机没有的（计划分数、引导进度、补全提问）改为按账号缓存 + 最短间隔（聚焦重读限频），断网用缓存并显示「截至」；小组件快照直接用首页卡片已读数据，不再自发 7 个 GET。 | 在线进首页：网络请求从约 17 降到 ≤3（布局/计划/引导在缓存过期时）；同一会话内来回切页不重复请求；断网首页各卡显示本机内容；定向测试覆盖请求计数。 |
| **LF2 活动** | 活动标签：「参加予定」读已报名活动域，评估列表用页面副本；断网显示「截至」而非空列表。活动详情/现场：已报名活动读不到网络时回退到 0115 的活动当天本机数据（报名、主办方发布的座位与推荐）。服务器：`/api/events/:id/overview`、`/venue` 的 GET 不再写库（试报名同步、受付号分配改到明确的写操作）。 | 断网可看已报名活动的详情与现场；GET 无写入的测试；活动标签断网有「截至」。 |
| **LF3 其他页面** | 收件箱在本机通知/对话域可读时停掉 15 秒未读数轮询；人脉分析恢复手机本机计算（0117 的 dashboard-graph 域，用户 2026-10-21 采纳建议），服务器分析只做 AI 洞察等本机算不了的部分；iOrbit、我的页的联系人汇总/未读/已报名计数改读本机；全局搜索的「人」先本机命中。 | 各页在线请求数下降并有测试；人脉分析断网可看且与服务器口径一致的对照测试。 |
| **LF4 服务器读取放大** | 秘书预览按需读、设上限；计划 v2 概要只读当前/活跃计划与最近日志；联系人汇总减少全量扫描；退会状态检查：加索引/缓存，查询失败时放行（不再全站 503），只拦写与敏感接口；活动报名 AI 自我介绍加防重复扣费和用量上限。 | 每接口的读取行数/查询数测试（读取小票）；失败放行测试；AI 幂等与上限测试。 |
| **LF5 本机清理与同步字段** | 最近搜索（全局、活动）按账号隔离并在退出/删号时清除；删除联系人队列并入正式待发队列（计入未同步提醒、按租约清除）；首页布局等缓存在退出/删号时清除；待办同步字段补 `deferralCount`；修正离线清单里删除/签到写入的错误标注。 | 换账号后看不到上一账号的搜索；退出时清干净的测试；deferralCount 同步测试。 |
| **LF6 防回归与收口** | 离线清单测试改为核对每个页面的实际读取来源（扫描页面代码里的网络调用与登记是否一致），文档按代码重生成；dashboard-graph 等数据域都有实际读者的检查；两端全量 + 模拟器断网冒烟（首页、人脉、活动、收件箱、Task）；更新核对报告。 | 清单与代码一致；故意加一个未登记网络读取时测试失败；断网冒烟全部通过。 |

**不在本轮（等用户决定）**：推送免打扰与每日上限、旧版计划生成关闭、需求匹配打分删除、两端算出不同结果的规则统一（角标、时区、「能见到的人」）。
