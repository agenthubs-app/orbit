# Sprint R18c — 账户：数据导出与退会

## 要实现什么

接在 R18b 认证与公开页之后，把 R18a 留在 App `/account`、Web 言語と外観及設定菜单里的数据权利入口接成可用功能。

1. **数据导出（D-21）**：选择人脈、メモ、プラン・ログ、イベント履歴，或选择「すべて（JSON）」。人脈可选 CSV / vCard；近期登录后创建任务，后台生成 ZIP，保存到私有文件存储。账号每天按东京日期最多接受 3 次导出，同时最多 1 个准备中任务；系统故障导致失败的任务不占额度。完成后用 Orbit 名义的事务邮件和推送通知。用户在登录后下载，下载 URL 有效 5 分钟，成品从准备完成起保留 7 天，过期后不能下载，历史仍显示结果。
2. **退会（D-22）**：先看按领域列出的清除范围和导出入口；本人主办活动仍有报名时，先中止或移交共同运营者。再用当前登录方式重新认证、确认申请，受理后立即发「不是本人操作请取消」事务邮件。申请后立即停止普通产品访问、使旧 JWT 失效并清理本机镜像/草稿；30 日内重新登录只显示「削除を取り消す」并可取消。到期清除任务按领域逐个清除本人数据和私有文件，记录每一步结果、支持安全重试。清除后可用同一邮箱全新注册（新 account id）；完成邮件进入不含个人资料的静态通用完成页。到期任务仅在本机测试库验证；生产调度与启用列为「待用户授权」。
3. **两端画面**：以 `b7-account-misc.html` #19–32、深色 #74 / #81 为基准。新 App 页面一律用 `AppScreen inset="kit"`；两端只调用 R31a / R31b 已交的新组件。缺组件要向 A 线提出请求。

## 做完能看到什么

- App：設定 → アカウント → 数据导出或退会。导出能看到选择、后台准备、完成、历史、过期；退会能看到清除清单、再认证、申请中与取消、清除完成。
- Web：設定菜单的「アカウント」「データの書き出し」和言語と外観页的两个数据权利链接都能进入同一流程；窄屏仍可返回设置。
- 导出邮件链接回到登录后的详情，下载请求重新校验本人及期限；通知里没有私有文件 URL。退会受理和完成分别发送事务邮件；完成链接打开静态通用页。
- 没有付费方案、App 内购或自动取消订阅的提示。原画板中的这些行按主会话代定改稿后再进像素门禁。

## 怎么验收

用本机测试账号走：选择范围 → 重复提交不重复计数 → 后台准备 → 邮件 / 推送替身收到完成通知 → 下载 ZIP 并核对内容 → 第 4 次被限额拒绝 → 过期不可下载；另测系统故障失败不占额度、同时只能有 1 个准备中任务。再走主办活动有报名时的阻止、未同步修改提示、退会申请 → 受理邮件 → 普通页面/API/同步不可用 → 新登录看到「削除を取り消す」→ 取消后恢复访问；另用本机测试库把时钟推进 30 日，核对逐领域清除、失败重试、通用完成页与同邮箱新账号。两端按画板逐屏验收；生产清除保持关闭。
