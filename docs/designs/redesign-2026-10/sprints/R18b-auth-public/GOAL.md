# Sprint R18b — 认证与公开入口

## 要实现什么

让还没登录的人从 Web 落地页或 App 欢迎页顺利进入 Orbit。Web 落地页照 b1 #0 重画；已登录访问 `/` 直接去 `/app/home`。登录、注册、找回密码、设置新密码在 Web 落地页弹窗和 App 全屏画面中各有完整流程；注册页的同意条款文字链接到公开法务页。保留邀请码等深链的安全回跳，Google 登录走已有的移动认证链路。旧认证与落地画面在新画面接通后清理。

ヘルプ、利用規約、プライバシー可在未登录时打开：Web `/help`、`/terms`、`/privacy`，App `/help`、`/legal/terms`、`/legal/privacy`；设置里的入口跳到这些公开页。ヘルプ是可搜索、可展开的静态 FAQ。支持邮箱未定时显示「準備中」，隐藏复制与邮件按钮；条款、隐私正文在发布前显示「公開前に掲載」，两项都是发布门禁。404、维护、App 强制更新和 Web 新版浮条分别显示可理解的出口，不把普通断网或普通 503 误报为维护。

`GET /api/app/version` 用独立的 `app-version` live 能力读取服务端环境变量，返回版本、可选维护态和 Web 构建标识；强制更新 `enforceMinimum` 缺省关闭，首次正式发布后才允许启用。App 启动及认证态不显示底栏的问题由 D 线在根导航壳中单独提交，C 线交付复现、接口和回归证据。App 未知路由显示 404，不再静默跳首页。

## 做完能看到什么

- Web：`/` 和未登录 `/app` 是 b1 落地页，已登录 `/` 进 `/app/home`；登录、注册、忘记密码、重置密码可从同一公开入口到达，宽屏、1024、390 和深色都有画板与截图。
- App：未登录首次进入时看到 b1 欢迎页；登录、注册、发送重置链接、设置新密码能连续走通，Google 入口可用；有会话或带目标的深链按既有规则返回，不重复展示欢迎页。
- 两端：公开帮助与法务页可从注册和设置到达；R18a 的设置占位改为跳转。支持邮箱与正式法务正文待发布授权；404 与维护态有明确去处。通知和数据权利仍归各自 Sprint。
- 版本：本地 live 接口可测，低于最低支持版本时 App 可进入强制更新页；正式发布开关仍关闭，Web 新版浮条只在确有新构建时出现。

## 怎么验收

用未登录、已登录、密码错误、已注册邮箱、有效与过期重置链接、Google 取消及成功、离线、普通 503 和明确维护态走完整操作链。Web 1440 / 1024 / 390 × 浅深，App iOS 模拟器浅深按画板逐像素比；缺的画板先补画。FAQ 搜索、邮箱缺省态、公开法务路由、版本开关、404 与回跳有行为测试；原有两端测试零新增失败。完整 SC、画板表、跨线请求和证据格式见 [PLANNER.md](PLANNER.md)。本页说明目标，实施状态以 REPORT 为准。
