## 逐项取舍与归属

- `.phone` / `.phone.mweb` 的 54 圆角、画框阴影、`.status` 30 内边距、`.island` 的 60 偏移和黑色，以及 `.web` 画框阴影，都是设计稿中的手机或浏览器外壳。按 README 通用规则 13 和决定表 §20 排除，不作为产品元素实现或补 token。
- iOrbit 起始卡片的 `line-height:1.45` 与现有 `--lh-body:1.5` 不等；Web 1440 内容间距 60、App 历史抽屉 / b8 390 历史弹层内容内边距 58、标题 `letter-spacing:0.01em`、键盘提示 `line-height:1` 也缺精确 token。交 A 线补正式 token / 组件参数后再做对应像素门禁；E 线不写近似值。画板 #54 为手动开启 pageContext 后状态，首次进入默认关闭另做功能截图，不用 #54 代验。
- 搜索框与输入框被标为「自由输入」，属于真实交互。建议问题卡、历史行、⌘K、菜单、@ 候选、确认卡均应走可操作入口。Web 起始页面的人脈 / イベント / プラン计数 chip 被标为「装饰 emoji」：其数字须由本人数据源产生；图标按画板和组件库，不能把整个 chip 当静态示例。
- 数据来源：会话、标题、最后活动与组织状态来自本人作用域 `GET /api/ai/conversations/sessions`；问答与草稿回执来自现有可靠发送 / entity-draft API；计划入口来自 `plan*Href` 和 intakes；R30 会話命中来自本人搜索服务。演示模式须明确标示示例。收件箱本人会话读取与 Web 选中深链依赖 B 线。
- b8 只提供 1024 / 390 的起始和历史状态；生成、实体草稿错误等没有同宽画板的组合附运行截图并标「设计稿无，不进门禁」。b4 / b11 相同状态以较新补板优先；App 系统状态栏和 Home 指示条由系统提供。
