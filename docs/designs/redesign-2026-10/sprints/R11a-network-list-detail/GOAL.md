# Sprint R11a — 人脈：列表 + 联系人详情 + 数据层

## 要实现什么

把「人脈」页和每个人的详情按新设计在 App 和网页上重做，并把背后的数据补齐：

- **人脈一覧**：顶上写着一共多少人、这个月新加了几个人；三个页签「すべて」「目標に関係」（和你现在的目标有关的人）「要フォロー」（有还没做完的 To-do 或跟进挂在这个人身上，和 Task 页的 To-do 是同一套）。每个页签上显示人数，总人数和本月新增不随页签和筛选变。每个人一行，前面三颗点表示这个人的信息有多全（●○○ 只知道名字，●●● 很了解），后面一个小标签写这个人是怎么加进来的（名刺 / LinkedIn / 連絡先 / 手入力 / 本人 / **イベント**）。可以按 段階（知り合い / 関係構築）/ 業界 / 地域 / 出会った場所（イベント / 紹介 / 訪問・商談 / その他）筛选。
- 列表上方的搜索框只在人脈里找人；右上的 🔍 打开全局搜索（App 进搜索页并带上已输入的词，网页打开 ⌘K）。从搜索页「近い条件なら」跳过来时，业界筛选已经选好。
- 「＋」打开「人脈を追加」弹层，背后就是人脈列表。
- **連絡先詳細**：名片式头卡、为什么值得联系、下一步、对方能提供的 / 在找的、往来记录；App 也有「なぜこの人か」和价值说明了。用招待码连上的人：能看到对方自己填的资料、哪些项目在同步、哪些因为你改过而暂停同步，可以改共享项目或解除连接。计划推荐的人显示「这个人符合某个人物类型吗？」确认卡，点 ✓ / ✕ 就记下来。资料被更新过的项目可以看到「以前の値」。
- **编辑和删除**：照设计稿改资料、选业界和职位层级；删除前确认，删完马上能点「元に戻す」撤回，30 天内也能恢复；这个人的メモ不会丢，恢复后照旧显示。没网时删除也行，联网后自动生效。（「最近削除した項目」一览留到下一期。）
- 联系人详情给「约面谈时间」留好位置，Task 那边（R20a）做好后直接挂上。
- 网页人脈页右栏放「每天一问」卡片；网页的联系人抽屉做成现成组件，首页（R10）以后直接拿去用。
- 删掉两端旧的「パイプライン」页；顺手消掉网页手机宽度深色模式下的开发警告。

App 的人脈列表照旧先读手机里的数据，没网也能看、能筛、能搜。

**不在本期**：人脈分析（構造 / 機会 / インサイト，R11b）；「登録内容の更新提案」（自己资料部分在 R18，联系人那一侧下一期）；转职冲突提示（下一期）。

## 做完能看到什么

- 两端人脈页长得和设计稿一样（网页 1440 / 1024 / 390、浅色和深色；App 浅色和深色），总人数、本月新增、三颗点、来源标签都是真实数据。
- 切到「目標に関係」只剩和计划有关的人，切到「要フォロー」只剩有未完成 To-do 的人；筛选、搜索、翻页都对。
- 点任何一个人进详情，信息齐全；招待连上的人、计划推荐的人、资料改过的人各有对应的那一块。
- 旧パイプライン页打不开了，原来指向它的链接也没了。
- 之前因为「人脈页还是旧的」而没过对照的加人、招待、导入、搜索画面，重新对照通过。

## 怎么验收

逐条走完列表（页签、筛选、搜索、翻页、＋、🔍）、详情（三类特别情况）、编辑删除；数据层有单元测试和接口测试，老版本 App 读新数据不出错；两端每个画面逐像素对照设计稿通过（超出的只能是数据文字、栅格化或对比度）；两端全量测试零新增失败；独立复核自己重跑测试和对照，产品负责人看截图拍板。
