# Sprint R01 — 设计源：一份 token 源生成两端，新配色覆盖旧配色

## 要实现什么

改版的颜色、圆角、字号、阴影、动效全部来自一份源文件 `shared/design/tokens.json`，由脚本生成 App 和 Web 用的文件。新值直接覆盖旧值，两端代码统一改用设计稿的名字（ink、surface、plum、coral……），旧名字一个不留。字体按界面语言切换，两端默认主题跟随系统。

## 做完能看到什么

- 打开 App 和 Web，现有页面已经是设计稿的新配色，浅色和深色都正常。
- 所有文字在对应底色上对比度 ≥4.5:1；设计稿里偏浅的几种文字颜色换成了加深版。
- 日文界面用日文字体，中文界面用中文字体，不再有中文衬线体。
- Web 默认跟随系统明暗，设置里可以选 自动 / 浅色 / 深色；App 也一样。
- 改颜色只改 `tokens.json` 一处，跑一次生成，两端同时生效；手改生成文件会被测试拦住。

## 怎么验收

开工后先出「旧颜色 → 新颜色」对照表给产品负责人确认（RD-07），确认后才改代码。收口时：两端对比度测试全部通过；生成文件与源逐字一致；App 5 个、Web 5 个代表页的浅色 / 深色截图前后对比，没有看不清或颜色含义错位；两端全量零新增失败。
