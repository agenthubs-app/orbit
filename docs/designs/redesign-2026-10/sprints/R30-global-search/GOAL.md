# Sprint R30 — 全局搜索（两端）

## 要实现什么

让用户在 Orbit 里**一处输入，三类都能找到**：人、イベント、会話。

1. **Web ⌘K 面板本体**：按 ⌘K / Ctrl+K，或点左栏和标题区的 🔍，打开 680 宽的面板。第一行就是无框的搜索输入，右侧是类型 chip「すべて / 人 / イベント / 会話」和「Esc」。输入「高橋」立刻看到分组结果：「人 · 2」（头像、姓名、会社 · 役職、右侧状态 chip 推進中 / 知り合い）、「イベント · 1」（活动 emoji、标题、「高橋 さんも参加予定 · 10/16」）、「会話 · 2」、「コマンド」（iOrbit に聞く：「高橋」⌘↵）。命中的字高亮。底部是「↑ ↓ 移動 / ↵ 開く / Tab 種類を切替」和右侧的「意味検索」开关状态。
2. **无结果也有出路**：搜「半導体 商社」找不到人时，面板居中显示 🔎「『半導体 商社』に一致する人はいません」和「286人の名前・会社・役職・メモを探しました」，下面给两组去处——「近い条件なら」（🏭 製造業 › 電子部品 12人、📦 商社・流通 35人，点开按业界筛人脈）和「ほかの方法」（✨ iOrbit に紹介ルートを聞く、🎟 イベントで探す）。
3. **App 全局搜索**：一个全屏搜索页（搜索行 + キャンセル + 同一排类型 chip）。初期显示「最近の検索」（可消去）和「こんな検索もできます」示例；输入后分组结果和无结果画面与 Web 相同。
4. **一套搜索服务两端同用**：服务端一个搜索接口把现有的人脉搜索、活动搜索（R27 的 `event-search`）合起来，加上分组、排序、命中位置和「近い条件なら」。两端只画，不各自拼接口。
5. **会話与意味検索按能力开关**：会話的搜索接口归 R21（还没开工），接口到位前不显示「会話」chip；「意味検索」要付费 embedding，本轮默认关、不调付费 AI，开启的实现与成本写在设计里等授权。
6. **App Task 左上 🔍 改接全局搜索**（交接表 R20-01）：现在跳人脈列表，R30 做完后打开全局搜索页。

## 做完能看到什么

- Web 任何已登录页面按 ⌘K：输入人名、公司、活动名都能找到，↑↓↵ 打开，Tab 切类型，Esc 关闭；1024 同样可用；390 照稿没有 ⌘K（G12），搜人走人脈页搜索框。
- App Task 页左上 🔍 打开全屏搜索页；人脈页的 🔍（R11）也可以接同一个页。
- 未登录打不开搜索接口（401）；搜索只在本人的联系人、本人能看的活动名单和本人的会話里找。
- 演示世界里按画板的示例（高橋 ×2、Japan SaaS Summit 2026 秋、半導体 商社 → 0 件）能复现每一张画板。

## 怎么验收

1. Web：登录 `qa@orbit.test`，按 ⌘K，输入「高橋」→ 三组（会話在 R21 前不显示）+ コマンド；↑↓ 到第二个人，↵ 打开联系人详情；Tab 切到「イベント」只剩活动；输入「半導体 商社」→ 无结果画面，点「製造業 › 電子部品」跳到人脈页并带上业界筛选；⌘↵ 把「高橋」交给 iOrbit（不发送，只预填）。
2. App：Task 左上 🔍 → 搜索页初期（最近の検索 / こんな検索もできます）→ 输入「高橋」→ 分组结果 → 点人进详情；キャンセル 回 Task。
3. 两端每个有画板的画面逐像素对照（Web 1440 浅 / 深、App 浅 / 深；设计稿没有的宽度与状态先按 [PLANNER](PLANNER.md) 的补画清单补画再比）。
4. 两端原有测试一条不变坏；新接口有 mock 成功、live 401 / 429、本人数据隔离的测试。
