# Sprint R07 — Web 导航壳

## 要实现什么

Web 所有已登录页面一次换成新外壳：左侧 84 宽的导航栏（ホーム / 人脈 / iOrbit / イベント / Task / 受信箱，底部 主催 / 設定），顶部主标题区，可选的右栏「次の一手」，⌘K 面板取代右下角悬浮球。旧顶栏和悬浮球删除。首页、收件箱、Task 这些新入口先放占位页或容器。

## 做完能看到什么

- 登录后任何页面左边都是新导航栏，没有旧的顶部药丸导航，也没有悬浮球。
- 按 ⌘K（Windows 为 Ctrl+K）弹出搜索和「问 iOrbit」面板。
- 窗口变窄时，导航栏先缩成只有图标，再变成底部胶囊。
- 「ホーム」是组件首页的占位，不再直接跳到 iOrbit；「受信箱」是一个完整页面；「Task」是四段容器，计划段先放空态。
- 默认跟随系统明暗，设置里可以切换。
- 示例模式的提示药丸在主标题区。

## 怎么验收

浏览器在三档宽度下走遍所有已登录页面，每页都是新外壳；键盘能操作左栏和 ⌘K；未登录访问新页面会跳到登录；旧顶栏相关测试迁移到新外壳后通过；两端全量零新增失败。
