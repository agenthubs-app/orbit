# Sprint R06 — Web 组件库

## 要实现什么

按同一份设计规格做出 Web 的通用组件库（五类），放在一个干净的新作用域 `[data-orbit-2026]` 里，用 CSS Modules 写样式，只用 R01 的 token 和 R03 的文案源。旧页面的样式不受影响。

## 做完能看到什么

- Web 有一套和 App 同规格的按钮、卡片、标签、弹窗、抽屉、Toast、开关、分段、空态、加载、离线提示等组件，键盘可以完整操作。
- Toast 在右下角最多叠三条；弹窗和抽屉按内容多少分大小（抽屉 520 / 380）。
- 本地和预览 / staging 环境有一个组件展示页，可以逐个看各组件的状态，正式环境看不到。

## 怎么验收

展示页与设计稿画板并排截图（三种宽度 × 浅色 / 深色）；键盘走查所有组件；新组件的 CSS 里没有写死的颜色；现有门禁和两端全量零新增失败。

完整验收项见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；状态见[登记表](../README.md#骨架登记表)。
