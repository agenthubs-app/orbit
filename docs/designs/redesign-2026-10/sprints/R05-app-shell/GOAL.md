# Sprint R05 — App 导航壳

## 要实现什么

App 打开就是 NAV-V3 的结构：底部玻璃胶囊五项 ホーム / 人脈 / iOrbit / イベント / Task。新增 Task 页，把日程、待办、笔记放进四段里，计划段先放空态。「我的」从首页左上头像进入，收件箱从首页右上 🔔 进入。二级页面不显示底栏，返回时回到原来的位置。壳做完冻结，之后各功能只往里放页面。

## 做完能看到什么

- 底栏是新的玻璃胶囊，五项切换顺畅；iOrbit 是普通的一项，点开是全屏。
- Task 里左右滑或点分段，就能在日历、To-do、计划、笔记之间切换；右上角「＋」新建当前段的内容。
- 以前的日程、待办、今天、笔记链接和推送通知，都会跳到 Task 对应的段。
- 首页左上是头像（进「我的」），右上是 🔔（有未读时显示红点）和「編集」（点了提示即将上线）。
- 进入任何二级页面都没有底栏；返回时回到进来的那个 tab，分段和滚动位置都还在。
- 断网时 Task 四段照常能看。

## 怎么验收

模拟器全流程走查（五个 tab、二级页往返、旧链接、推送跳转、断网）；320 宽和 2 倍字号下底栏不溢出；所有导航相关测试迁移到新结构后通过；两端全量零新增失败。
