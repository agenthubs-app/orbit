## 1. 结论

> **复核后修订（2026-10-12）**：独立复核 [REWORK-REVIEW](REWORK-REVIEW.md) 判「不通过」（S1、S2、M1–M5、m1–m7）。本节与第 3、5 节已按修复后的结果改写，修复明细见第 9 节；首页顶栏 `.hhead` 按主会话 2026-10-12 的范围决定追加进本次。

- **壳的几何、颜色、图标已逐像素对齐**（iPhone 16e 模拟器，浅 / 深都截；最终一轮 `r9/`，顶栏改动后 Task / マイページ 复跑 `r10/`）：Task 顶栏三段式与分段、首页 `.hhead`、二级页顶栏、雾面背景（取样色值 ±1）、底栏胶囊的位置 / 尺寸 / 边线 / 选中块 / 图标位置与颜色。
- **局部门禁（30px 细带）仍有超阈带**，Task / マイページ 顶栏与底栏在 0.02–0.047 之间，首页 `.hhead` 约 0.09。来源有四类（逐带看过 triptych）：
  1. **数据**：Task 顶栏日期「10月12日（月）」↔ 示例「10月7日（水）」（已写 `[data]`）；首页头像首字、日期、问候（时段与姓名）。
  2. **假名粗体字形**：Mac 上 Chrome 按字重取 Hiragino Sans W7 / W8，iOS 系统字体回退的假名更窄更细（实测把标题显式设成 `HiraginoSans-W8` 后宽度粗细即一致）；全角括号「（」的留白也随字体不同。影响分段「カレンダー / プラン / メモ」、底栏标签、マイページ 标题与副标题、首页「編集」（药丸变窄，带动 🔔 右移 1px）。**等用户拍板**（主会话推荐 (b)：App 日文显式用 Hiragino 各字重）。
  3. **图标亚像素**：门禁已改设计侧 3x 渲染（`37209736`）；Yoga 与 Chrome 对 x.5pt 的取整方向不同，底栏 21pt 图标竖边差 1 个设备像素，只框图标行 0.027–0.029。按主会话：不在 App 里挪图标去凑。
  4. **玻璃胶囊透出的旧正文**（复核 M5）：设计稿胶囊下透出的是新正文，实现透出旧正文；深色首页 / イベント / メモ 的底栏带 0.03–0.04 主要来自这里。属正文，R10 / R26 / R20 换新屏后消失。
- **RD-05 壳内例外扩到 App**：底栏未选中标签、Task 日期、二级页副标题、首页问候用 `--ink-3`——主会话 2026-10-12 确认（沿用用户对 Web M1 的决定），README RD-05 已补，按通过算。
- **整屏仍不过**：正文是旧屏（见第 3 节表）。
- **D07 已做**：被盖住的一级页自己画一份底栏（`TabPageBar`），原生转场把它和一级页一起推走、被二级页盖住；返回时从离开的页面下面露出，转场结束后交回根部底栏（录屏抽帧见第 9 节）。

## 10. 假名字形 (b) 落实（用户 2026-10-12 选 (b)）

**各字重可用情况**（iPhone 16e 模拟器 iOS 26.1 运行时 `System/Library/Fonts/Core/HiraginoKakuGothic.ttc` 的 name 表）：公开字面 `HiraginoSans-W3`、`W4`、`W5`、`W6`、`W7`、`W8` **全部可用**，不需要替代字重。系统给日文默认回退的是隐藏的 `.HiraKakuInterface-W*`（界面专用切，比 Hiragino Sans 窄），这正是之前假名带对不上的原因。

**字重映射按实测，不是 W3/W6/W7/W8**：用 CDP 读门禁环境里设计画板的实际字面——字体栈以 SF 开头（门禁 `appDesignFontFix` 之后，与 Web 实现一致），假名回退到 Hiragino Sans 时 Chrome 按 CSS 字重匹配落档：400 → W3、500 → W4、600 → W5、700 → W6、800 → W7、900 → W8（实测分段 700 = `HiraginoSans-W6`、顶栏标题 800 = `W7`、问候 500 = `W4`、底栏标签 700 = `W6`）。之前看到的「800 → W8」是门禁修字体之前 Hiragino 作主字体时的落档。为了和设计图（以及 Web 实现）一模一样，token 按实测写。

**实现**：
- token：`shared/design/tokens.json` 新增 `font.face.ja`（400–900 → 字面名，App 专用；`font.family.ja` 是 Web 的 CSS 字体栈，未改），生成并同步到 App 副本 `src/api/design/tokens.ts`。顺带按主会话要求把 `font.family.num`（`--font-num`）的回退照设计稿改为 `"Noto Sans JP"`（原为 `system-ui`）。
- `UiText`：iOS 且界面语言为日文时，把字符串里的假名 / 汉字 / 全角符号段落包进嵌套 `Text`，用对应字重的 Hiragino 字面（`fontWeight: normal`，避免再合成加粗）；英文、数字仍是系统 SF。其他平台、其他语言不变。旧屏直接用 RN `Text` 的地方仍走系统回退，随各功能 Sprint 换 `UiText`（交接表 G24）。
- `cjkLift` 按新字形重新量：顶栏标题假名 −2 → −1、副标题假名 −1 → 0、底栏标签英文 −0.33 / 假名 0；分段维持 −1 / −1.5（−1 / −1 实测更差）。
- impact：`UiText` **CRITICAL**（直接 132 处 / 55 个文件）。对策：只在 iOS 日文生效、只拆字符串子节点；App 全量测试；门禁全量重跑。
