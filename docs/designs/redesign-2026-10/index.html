这一版做出的结构决定

按成熟产品惯例自定，可推翻
  1. 两端同一套 IA：ホーム / 人脈 / イベント / プラン（Web 另有 iOrbit、受信箱）。对标 Money Forward ME / Eight：底栏只放「看」的地方，「做」的动作集中到 ＋追加。
  2. 首页是今日看板，不是 AI 对话。AI 变成每页右上 ✨ 圆钮（App）与右侧常驻栏 + ⌘K（Web）。原 App 中央 IORBIT 键取消，避免和「＋追加」两个悬浮主键打架。
  3. 活动评估放在「イベント」页顶部，结果页 0–100 分 + 三项内訳（目标一致 / 会える人 / 时间对效果）+ 注意点；Web 用主从布局，点卡片右栏切换。
  4. プラン 升为一级：App 补齐独立页；匹配候选永远要用户 ✓/✕ 确认。
  5. 人脉四页签合一屏：总量环 + 业界 + 缺口三卡在上、列表在下；详情 Web 用右侧抽屉（关闭回原位置）。
  6. 沿用既有硬约束：邮件/消息止于草稿（按钮文案明示「送信はしません」）、处处有据但默认收起（「?」展开）、示例数据带「サンプル」角标绝不写库、不做即时聊天。
  7. 空状态：每页只给一个主动作 + 马卡龙次要入口 + 虚线幽灵行/淡化示例预告「之后能看到什么」；未达阈值（如人脉分析 <10 人）显示解锁进度而非空图。
