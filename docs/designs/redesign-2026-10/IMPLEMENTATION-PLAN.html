Orbit 新 UI 落地方案

把 App（repos/orbit-app）和 Web（repos/orbits）按 NAV-V3 和计划 v2.2 的新设计落地。两个人在各自本机并行开发。这一页给两位审阅用，完整原文在同目录的 IMPLEMENTATION-PLAN.md。

三句话结论

  • 这次是按屏替换，不是换配色：两端现有视觉都不是新设计的前身，导航整体换掉，还要新增 Task、首页组件、计划 v2.2、活动评估、招待コード、AI 秘書。做法沿用 0918 的「一张设计屏 = 一个新组件文件，接真实数据」。
  • 大部分画面能直接用现有接口：真正要动后端的集中在计划 v2.2、活动评估、招待コード、推送与秘書、首页布局、账户类，全部只加不改。
  • 先换壳和 token，最快看到效果：P0–P2 后端几乎不动；最重的计划 v2.2 放在 P3，需要付费 AI 和生产迁移授权。

双人协作

线 A · 后端 + Web · 你

全部迁移、共享契约（shared/contract、shared/api-schema、shared/compute）、features/**、app/api/**、Web 页面与壳、Web 文案。

线 B · App · 伙伴

App 壳、屏幕、组件、离线 outbox、原生能力（小组件、NFC、StoreKit）、App 文案目录。契约副本只能通过 npm run sync:contract 更新。

为什么按端拆：App 只经 HTTP 调后端、不 import Web 源码，两人物理上很少改同一个文件；按领域纵切的话，两人都要改导航壳、token 和 8,771 行的 i18n 大文件。

契约先行

需要新接口时，线 A 先合入一个只含契约的小提交：共享类型、zod 定义、fixture、返回 fixture 的 mock 路由。线 B npm run sync:contract 后就能用 mock 开发，真实实现接上时契约不变。

契约只加不改

新字段一律可选；不删除、不改名；枚举只加值。必须破坏时两人当面对齐、同一天合入。

迁移号只由线 A 分配

迁移按模块编整数版本、只能往前追加，已发布的 SQL 一改就报错。两个人各写一个 v2 会直接撞号，所以线 B 有后端需求就提给线 A。

分支

各自开 redesign/<线>-<主题>，以 chat-agent 为基线，小步合回；每天至少 git pull --rebase 一次。编号：Web W0062 起，App 0141 起。

热点文件单一负责人

App 导航、AppScreen、i18n、tokens 归线 B；Web 壳、layout 归线 A；orbit-reference-styles.tsx 冻结不改。共享 token / 图标 / 文案源归线 A，线 B 同步取用。

本地环境独立

每人自己的本地 Postgres，测试用独立 orbit_test；.env.local 不入库不共享；默认不配 DeepSeek key，真实付费调用只在授权次数内、由授权人本机执行。

提交模板

契约变更的提交以 contract: 开头并写明「App 需要 sync」；线 B 拉取后先跑同步测试再开发。

纯前端改动

设计 token

以原型 kit/tokens.css 为准生成一份 tokens.json，脚本产出 App tokens.ts 和 Web CSS 变量。键名统一为 ink / surface / plum / rose / mac / coral / ok；旧名迁移期保留别名。

对比度

新的 ink-3、马卡龙文字色、coral 在浅底上达不到 4.5:1，两端门禁都会失败。文字用色调深到达标，原值只用于图形和装饰。

字体

去掉 Noto Serif SC 和简中字体栈；Web 用 Hiragino / Noto Sans JP，App iOS 用系统字体（日语环境下就是 Hiragino）；数字等宽。新字号阶要先改 Web 刻度门禁。

图标

原型里的 50 个线性图标导出为一份共用数据；App 用 react-native-svg 替换 Ionicons（72 个文件，随屏幕逐步换），Web 替换自绘 Icon。

日文化

App：日文目录已有 2,184 个键，另有约 2,777 行硬编码中文，随屏幕替换一起抽出。Web：约 2,615 处文案只有约 248 处有日文，新屏一律写日文并在类型上设为必填。日期「10月7日（水）」等做成共享格式化函数。

导航壳

App：OrbitTabBar（HIGH）、app-navigation.ts（HIGH）、AppScreen（CRITICAL，只改内部渲染、props 不变）、新 Task 路由。Web：新左栏 OrbitSideNav + 新壳 Orbit2026Shell，替换 OrbitTopNav / AccountTopNav（都是 CRITICAL，逐域切换）；悬浮球改 ⌘K；/app/home 改为组件首页。

组件库

两端各写一份、规格同源：卡片、胶囊按钮、chip 语义色、筛选、分段、列表行 + 左滑、马卡龙头像、进度条、环形图、构成条（斜纹）、浓度三点、来源 chip、Toast（替换 App 11 处 Alert）、确认框、动作表、抽屉、底部弹层、虚线确认卡、开关（App 现在一个都没有）、空状态、示例角标、骨架屏、离线横条、配额 chip、首页组件框架。

交互规范

可撤销的不弹确认，直接做 + 「元に戻す」；AI 写入先出虚线确认卡、结果原位变化；Orbit 里没有「送信」按钮；统一缓动；示例数据只在前端。
