手机端顶部：同一级页面同一个高度

现状取自线上（orbitailink.com，375 宽）11-23 的实测。红色虚线是正文第一块内容的起点，数字是它离浏览器可视区顶端的距离。左边现状，右边提案。

现状的问题

  1. 每页都有两层顶部：先是「O Orbit + 收件箱 + 头像」一行，下面再来一行页面标题。品牌行在应用内不提供信息，底部导航已经说明了你在哪。
  2. 标题有四种画法：首页、Task 没有标题；人脉靠左；iOrbit、活动、收件箱居中，其中活动还带一行副标题。
  3. 活动页叠了五层：品牌行、标题、页签（右边还竖着放了搜索和「下一步」）、搜索框、筛选，正文从 —px 才开始，一屏 812px 的四成多。
  4. 同级页面起点相差近 300px：首页 —px，活动 —px。

提案：三条规则

  1. 一级页（底部导航的五个 + 收件箱）只有一行顶栏，高 52px：左边是页面标题（20px 粗体），右边是这一页的操作（最多 2 个图标）、收件箱、头像。品牌行取消；首页的标题就是 Orbit 标志。
  2. 有页签的页面多一行页签，高 40px：页签铺满宽度。除此之外顶部不再加任何固定行。
  3. 筛选、搜索框、统计数字属于正文：跟着内容一起滚走，不占固定高度。活动页的搜索框收进顶栏的搜索图标；「下一步」改成顶栏里的一个图标；副标题「符合条件 N 场」移到列表上方。
  4. 二级页（详情、设置）不变：返回 + 居中标题一行，也是 52px。
  5. 结果：没有页签的一级页正文从 60px 开始，有页签的从 110px 开始。

对标成熟产品的做法

  1. Instagram、LinkedIn、X 的手机网页：一行顶栏，左标题或标志，右两三个图标；没有单独的品牌行。
  2. Luma、Notion 手机端：页签紧贴顶栏下方，筛选在正文里。
  3. iOS 大标题导航：标题靠左，下滑后收进顶栏；二级页才用居中标题 + 返回。这里一级靠左、二级居中，沿用同一套区分。
  4. Material 的顶部应用栏：操作图标最多 3 个，再多收进「更多」。这里页面操作限 2 个，加收件箱、头像共 4 个。
