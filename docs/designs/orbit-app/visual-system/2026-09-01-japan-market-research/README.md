# Orbit 日本市场成熟产品设计研究

研究日期：2026-09-01

## 结论先行

日本市场中成熟的业务与效率产品，产品内部通常并不依赖夸张的视觉隐喻。它们普遍采用熟悉的列表、搜索、标签、底部导航和详情页结构；品牌感主要来自严格控制的品牌色、字重、图标或插画语言，以及每个页面唯一明确的高频动作。

这意味着 Orbit 的“自己的风格”应该是一套稳定的视觉语法，而不是装饰层：统一的主色与强调色、清楚的中文排版、可识别的图标、克制的插画，以及贯穿 AI 首页、今日、关系收件箱和分析页的同一套信息层级。

## 方案生成约束

- 每个方向必须对应一组可指出来源的成熟模式。
- 只借鉴设计原则与交互习惯，不复制产品名称、Logo、文案或具体页面。
- 四个核心页面统一呈现：AI 首页、今日、关系收件箱、关系分析。
- 收件箱使用熟悉的消息流；消息类型包括对话、邮件/日程信号、提醒和活动准备。
- 分析页使用直接标注的横向柱形图，适应中日韩长标签。
- 日期锚点统一为 2026-09-01（周二）。
