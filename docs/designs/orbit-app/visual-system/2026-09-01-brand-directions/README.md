# Orbit 全局视觉系统方向

这组视觉稿用于选择 Orbit 整个 iOS 产品的品牌与界面语言，不是收件箱或图表的局部改版。每个方向都同时覆盖 Orbit AI、今日、关系收件箱和人脉分析，用来验证同一套设计语法能否跨页面成立。

## 共同产品基础

- 核心语义：真实关系、上下文、来源、可信度、时机与下一步行动。
- 核心用户：创业者、BD、顾问和高频活动参与者。
- 保留现有功能与内容模型；当前只探索视觉系统，不修改生产代码。
- 收件箱保持统一消息流；分析图使用适合中文长标签的横向比较。

## 方向

1. [Orbit Trace / 关系轨迹](./01-orbit-trace.png)：以贯穿页面的关系轨迹和节点统一列表、时间线、来源与图表。
2. [Signal Observatory / 关系观测站](./02-signal-observatory.png)：以单一深色观测带承载关键实时信号，形成“先观测、再行动”的跨页节奏。
3. [Trust Ledger / 关系档案](./03-trust-ledger.png)：以来源标记、确认状态和规则化排版强调可信关系上下文。
