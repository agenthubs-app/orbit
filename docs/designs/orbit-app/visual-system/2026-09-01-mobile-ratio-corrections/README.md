# Orbit 多页面方案：移动端比例修正版

日期：2026-09-01

本目录修正了上一轮 20 套六页面总览图的页面比例。旧版在 `1536×1024` 画布中使用 3×2 网格，使单页接近 1:1；本版将每套方向拆成 A/B 两张图，每张只放三个完整竖屏页面。

## 固定规格

- 每张总览图：`1536×1024`。
- 每个页面：保持 `390×844` 的移动端宽高比，三个页面横向并排。
- A 板：全部人脉、联系人详情、引荐机会。
- B 板：活动详情、活动签到、设置与数据源。
- 页面只展示应用内容，不使用手机外壳、状态栏、设备阴影或透视效果。
- 人物与活动照片使用自然裁切，禁止横向拉伸。
- 日期锚点：2026-09-01（周二），界面使用简体中文。
