# 原设计精修注意项

压缩仅改变图片编码，未修订或删除原设计中的这些注意项。执行时以中文规格与各页“图像校订”为准。

本包达到“逐页视觉参考＋功能交接”的用途，不是全部像素与交互已定稿。完整修正指令见各页的“图像校订”。

| 页面 | 精修重点 |
| --- | --- |
| P06、P10、P21、P31 | 移除生成的 200/500 字计数器，除非真实规则确认需要 |
| P11、P25 | 名片道具与照片标语不是业务数据或品牌文案 |
| P14 | 用“2 张图片 · 1 张双面名片”，区分图片数和新增人脉数 |
| P27、P41 | 合并重复的编辑／完成入口 |
| P29、P39、P40、P46、P69 | 删去生成的泛化文案；示例摘要和地点不反推真实数据 |
| P45 | 设备权限是扩展设计，现有服务权限能力须保留 |
| P55、P58 | 移除不一致的额外人数；P58 正确页头为“现场模式” |
| P56 | 题集配置须是配置行，不是参与者答题框；答题框只在预览状态 |
| P64 | 章节错字改为“登录账号” |
| P67、P68 | 全局建议／全部行动不限定一个人，移除额外单人资料块 |
| P70 | 推荐兼容页不额外内嵌全量活动；按钮跳转活动发现页 |

头像和主办方示意图尚未做全包素材统一；不能凭图像判断账号或联系人身份。最终字号、触控区域、固定区域和安全区仍需在可编辑设计稿中精确标注。生成文字优先服从中文规格。
