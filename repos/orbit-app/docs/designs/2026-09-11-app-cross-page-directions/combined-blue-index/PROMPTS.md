# 图像生成说明

本包保留用户已批准的首页原图，其余 71 个页面／状态由 ImageGen 分别生成。P03、P05、P07、P13、P33、P35 做过一次针对性校订；初稿保留在原始生成目录，交接包 `screens/` 只保留当前采用版本。

## 视觉来源

首页 V3 02-split-day 提供密度与底栏基准，跨页 02-blue-chapters 提供浅蓝章节，03-aligned-index 提供字段对齐和细蓝线。P08 生成后也作为后续页面的一致性参考。原始提示逐页保存在 [完整生成记录](GENERATION_CHECKPOINT.json)；原始提示中提及的参考编号只对该次实际参考图列表成立。

每页只生成一个屏幕，不裁切多页拼图。画面细化说明也附在 `pages/` 对应文档。提示使用虚构人物和活动，不含真实账号密钥。所有图像均保留原始输出，没有用程序绘制或补字修改。

## 尺寸

设计目标是逻辑 390×844pt；生成请求目标为 1170×2532px 或同比例。实际文件为 853×1844px 或 853×1843px，以 [素材清单](ASSET_MANIFEST.json) 为准。不要声称输出达到请求像素，也不要将其当作可编辑矢量稿。最终组件尺寸由 UI 规格约束。

## 使用原则

逐页图像是视觉参考。图片中偶发字数计数器、额外说明、重复入口和示例头像差异均不改变功能规格，精修要求见对应页面与检查记录。原图之外的融合页面尚未逐张获批，不应据此宣称 UI 已上线。
