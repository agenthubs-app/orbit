# Handoff: Orbit iOS 视觉改版 · Ink & Signal

## Overview
Orbit 是一款面向办公人士的人脉 / 日程 / 活动管理 App，内置 AI 助手 **IORBIT**。本次只做 **UI 视觉改版**，**功能、页面结构、信息层级、底栏顺序与首页 Split Day 布局全部不变**。最终选定方向为 **1c Ink & Signal**：白底、墨黑字、唯一信号蓝、发丝线分区、零阴影、大数字。

本包含：35 屏设计稿（HTML 源 + PNG 截图）与本文档。

## About the Design Files
`Orbit 改版方向.dc.html` 与 `TabBar.dc.html` 是 **用 HTML 绘制的设计参考稿**，用于表达预期外观，**不是可直接复用的生产代码**。请在目标代码库（`agenthubs-app/orbit`，iOS-first；web 端参考 `repos/orbits/shared/ui/theme.ts`）现有技术栈与组件体系中 **重新实现** 这些界面。若尚无对应组件，按本文规格新建。

## Fidelity
**High-fidelity。** 颜色、字号、间距、圆角、边框均为最终值，请按像素级还原。文字内容为示例数据（人名、公司、活动均虚构），接入真实数据即可。

## Interactions & Behavior
- **导航**：主 Tab 页保留底栏；所有二级页去底栏，用 48px 导航栏返回。返回文字为上级页名（如「‹ 人脉」）。
- **底栏**（见 `TabBar.dc.html` theme=ink）：5 项，中央 IORBIT 为 46×46 墨黑方块（15px 圆角）+ 10px/700 字距 .06em 标签；其余项 60×56，激活态背景 #EEF3FF、图标文字 #0A5CFF，未激活 #6B7280；容器 72px 高、白底、1px #E6E8EE 边、36px 圆角、阴影 `0 10px 28px rgba(11,18,32,.10)`（底栏是全系**唯一**允许阴影的元素）。
- **按钮**：主操作 50px 高 #0B1220 实心白字 15px/700，12px 圆角；次操作 46px 高 1px #0B1220 线框 14px/600；仅「发消息」「发送」「登录」等强 CTA 使用 #0A5CFF 实心。按压：opacity .7，100ms。
- **Tab / 分段控件**：下划线 Tab 激活为 2px #0B1220 底线（`margin-bottom:-1px` 压在 1px 分隔线上），文字 800；分段控件激活项 #0B1220 实心白字。切换无动画或 150ms ease-out 下划线位移。
- **复选框**：22px（列表）/ 16–20px（紧凑）方框，6px 圆角，1.5px #0B1220 边；勾选后 #0A5CFF 实心 + 白色 3px 描边勾。
- **IORBIT 对话**：用户消息无气泡；AI 回复流式渲染，结构化列表编号为蓝色大数字；引用卡（活动 / 人脉）可点击跳转；失败态见上。AI 只读，不自动写入待办 / 日程。
- **加载**：骨架屏使用 #F5F7FA 色块，禁止 spinner 覆盖整页。
- **空态**：图标 64px 线框圆 + 22px 标题 + 14px 说明 + 主 / 次按钮，垂直居中偏上（top ≈ 250px）。
- **大字号**：支持 Dynamic Type 到「较大」档；双栏布局在该档及以上改单列。

## State Management
- 首页：`selectedDate`、`schedule[]`、`todos[]`、`followups[]`、`events[]`、`unreadCount`
- 人脉：`contacts[]`、`filters{industry, source, status}`、`query`
- IORBIT：`messages[]`（含 `status: pending|done|error`、`errorCode`）、`context{events, notes, contacts}`
- 日程：`view: day|week|month`、`cursorDate`、`now`（当前时间线每分钟刷新）
- 待办 / 跟进：`tab: open|done`、分组按 `dueDate` 计算「今天 / 之后 / 已完成」
- 运营台：`registrations[]`（`pending|approved|checkedIn`）、`capacity`
- 权限：`role: owner|admin|participant` 决定运营台可见性
