## 本轮明确的设计边界

用户已选择[上一轮第三款悬浮长岛底栏](../2026-09-11-bottom-navigation/03-floating-island.png)的按钮风格；这个选择只批准底栏方向，不批准那张图的首页内容。底部仍为：首页／人脉／中央 IORBIT／活动／我的。IORBIT 仍进入独立全屏工作区，不变成首页上的聊天框。

用户明确否决上一轮的大“首页”标题、大字号和按功能逐项平铺的构图；本轮删掉顶部“首页”，按不同主场景重组信息，并按追加要求大胆拉开五案的差距。不是所有功能都必须出现在每一屏，未显示的内容仍通过既有入口访问。

## 生成与检查边界

五张均使用内置 ImageGen 独立生成，已在主会话逐张显示一次；没有批量拼图，没有在代码中画假截图。每个调用的完整文字与图片角色见 [PROMPTS.md](PROMPTS.md)。

已目视检查：五案没有顶部“首页”；五个底部入口及顺序保留；底栏是同一悬浮胶囊风格；五种构图可区分；正文总体比上一轮紧凑；样例日历以 2026-09-11 周五为基准，次日为周六。

仍需明确的限制：

- 指定画幅为 390×844 逻辑尺寸。第二至第五张实际为 853×1844，比例接近目标；第一张实际为 935×1683，生成器没有遵守相同比例。保留原图供构图选择，未拉伸伪装成统一手机尺寸；若选择第一张，先重新生成正确画幅。
- 字体目标是正文 14–15pt、标题最多 20pt，但栅格稿不是精确字体标注。第一、第四、第五张的强调标题仍比目标显大，尤其第四张；不能把“提示词写了 20pt”当成“已落实 20pt”。选案修订须收小这些标题，并以真实手机尺寸复核。
- 局部按钮和第四张色块出现渐变／高光，部分阴影偏重。这不是新 token 已被批准；选择后应按新的视觉决定统一。
- 第三张侧边照片是轮播预览的有意截切，不可据此裁掉姓名或操作。所有照片与头像均为生成样例，不能推断联系人有高质量原图。
- 第一张存在活动名重复，第四张任务换行仍可优化。第二张时间轴需要在真实布局中校准时间与卡片高度，不把示意图当时间比例的精确测量。
- 未运行 App、原生测试、动态字号、安全区、触控或无障碍验证；没有修改 API、共享契约或同步行为，不构成 Web/App 业务对齐完成。
