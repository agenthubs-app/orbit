# Sprint 0143 — 活动准备页「加入日程」可断网、不重复

## 要实现什么

在活动准备页点「加入日程」，走和日程页一样的保存方式：断网或网络中途失败时进待上传队列、标「未同步」；连点两次只生成一条；时间按手机所在时区，而不是固定东京时间。

## 做完能看到什么

- 断网点「加入日程」，日历上出现这条日程并标「未同步」，联网后到达服务器。
- 连续点两次或重试，服务器上只有一条。
- 手机时区不是东京时，日程时间仍然正确。

## 怎么验收

App 定向测试覆盖断网、重复点击和时区；App 全量测试和类型检查通过。
