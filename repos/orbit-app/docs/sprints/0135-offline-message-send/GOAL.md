# Sprint 0135 — 断网也能发消息

## 要实现什么

断网时在聊天页写的消息，点发送后排进队列，气泡下方写「待发送」，联网后自动发出，换成服务器时间。网络不稳重发不会变成两条。如果联网前对方撤销了关系，这些消息不会补发，而是在你自己的收件箱顶部留一行「未能发送」，可以复制内容或放弃。

## 做完能看到什么

- 断网时聊天页的发送按钮可用；新消息排在最后，标「待发送」。
- 联网后消息发出，对方收到一条，不重复；「待发送」换成时间。
- 服务器拒绝时气泡下方写「未发送」，可以重试或复制。
- 对话被撤销后，收件箱顶部显示「N 条消息未能发送：这段关系已结束」。
- 标记已读、存草稿仍然需要联网。

## 怎么验收

「本机数据库扮演服务器」测试里 A、B、C 三个账号，验证重发只存一条、序号连续、撤销后不补发、C 看不到；Simulator 与另一账号互发，断网发送后恢复。
