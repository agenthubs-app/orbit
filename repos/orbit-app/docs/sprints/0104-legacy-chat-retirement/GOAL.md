# Sprint 0104 — 旧 chat 退役

## 要实现什么

Orbit 有两套「消息」：旧的 chat（`messages`/`conversations` 集合，只有演示数据，已经没有自己的页面）和新的「关系沟通」（两个 Orbit 用户互发）。旧系统还被新系统借用了几个零件，其中两处因为编号对不上本来就是坏的，另外每次打开网页 iOrbit 页或保存草稿都会把旧数据整类全读一遍。本 Sprint 让旧系统退役。

同时修一个 0100 发现的跨端问题：App 收件箱遇到不认识的通知类型时整个列表解析失败，改为跳过无法识别的条目。

## 做完能看到什么

- 回复草稿照常能存，并且存在新系统的对话上。
- App 收件箱不再调用隐私设置、「允许分析」开关；聊天详情不再调用「提取要点」。
- 网页 iOrbit 页打开时不再读取旧 chat 数据。
- 旧接口、旧服务、旧演示数据删除；棘轮减 2。
- App 收件箱遇到未知通知类型时，其余通知照常显示。

## 怎么验收

草稿在新系统对话上的存取测试；App/网页相关页面在 phoneweb 上走一遍；旧接口返回 404；收件箱未知类型反例测试。

设计依据：「消息数据方案」M1。完整验收项见 [PLANNER.md](PLANNER.md)。
