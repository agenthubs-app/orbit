# Sprint 0022 — 待办统一与人脉筛选

让所有具体行动都在同一个待办入口管理，人脉待办只是其中一个筛选视图。

完成后应能：

- 在待办中切换“全部／人脉”和“未完成／已完成”，同一事项只保留一个 ID。
- 看清事项关联的人，完成或重新打开事项，不顺带改变联系人的“需要联系”状态。
- 从旧跟进链接进入人脉待办，继续找到原有草稿、建议和提醒入口。
- 在人脉页面查看需要联系的人；首页不再承担独立跟进入口。

验收覆盖筛选、真实点击、登录后返回、失败与换号隔离，以及同一待办在两端的回读。首页活动区由 0011 实现，“记笔记”快捷按钮由 0018 接入真实创建页；本 Sprint 不重复修改首页。
