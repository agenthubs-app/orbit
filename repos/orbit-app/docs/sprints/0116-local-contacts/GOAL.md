# Sprint 0116 — 联系人放进手机

## 要实现什么

在会场刚认识一个人，想翻出他的资料、看看之前聊过什么——这时往往没有信号。本 Sprint 把你的联系人连同关系、来源记录、联系人详情状态（以及 0114 确定的其他附属数据）放进手机，联系人列表和详情改为先读本地。

## 做完能看到什么

- 联系人列表、搜索自己的联系人、联系人详情，先立即显示手机上的内容，再在后台补上新变化。
- 断网时能看联系人、关系阶段、来源记录（这条信息从哪来），并标明「截至某时」；编辑提示需要联网。
- 别人的联系人不会进你的手机；你删掉的联系人下一次同步后从手机上消失。
- 打开联系人页不再每次整份下载，读取量明显下降。

## 怎么验收

「本机数据库扮演服务器」的双账号测试逐项检查；phoneweb 与 Simulator 开飞行模式打开联系人列表、搜索、详情。
