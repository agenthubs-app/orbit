# Sprint 0038 — 三类通知与统一记录

## 要实现什么

让每条通知明确属于提醒、建议或动态，显示原因和可追溯来源，并让 Web 与 App 操作同一条记录。

## 做完能看到什么

- 通知仅有全部/提醒/建议/动态筛选，图标与文字一致；约谈改期、名片批次结果等真实变化有明确内容。
- 点开可以看到来源、时间和具体操作；读过、忽略、已处理不会完成源任务。
- 两个端对同一通知的阅读和处理结果一致；来源删除或无权限时给出明确状态。

## 怎么验收

通过行为测试与实际运行的 Web/iPhone 17 Pro Simulator 验证；两端使用共同后端和同一 QA 账号，通信另用第二个已授权测试账号。 测试和界面可见不能替代业务持久化与跨端回读。
