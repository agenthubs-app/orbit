# Sprint 0010 — 个人事项能创建、修改，也能清空日期和地点

## 要实现什么

用户不用关联联系人也能创建个人事项，并可靠地编辑日期、时间和地点，在各页看到相同结果。

## 做完能看到什么

- 明确清空的字段重开后仍为空；只有日期时不凭空补午夜截止时间，未提交的标题和备注不会被夹带保存。
- 修改日期后的提醒符合批准规则；失败保留输入，冲突不覆盖远端，重复提交不多建事项。

## 怎么验收

验证创建、编辑、清空和失败保护，核对首页、待办、日历与 Web/App 同一事项及提醒；公开活动预览不自动创建私人事项。
