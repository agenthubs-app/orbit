# Sprint 0148 — 首页人脉小组件：一眼看到人脉分布

## 要实现什么

首页的人脉小组件不只是人数和头像，而是直接展示你的人脉分布在哪些行业、地区或来源，让「人脉在变大、变广」看得见。

## 做完能看到什么

- 小组件上方是总人数和本月新增，下方是一条分段比例条和前几名的图例（例如「IT·互联网 32%」「制造 18%」「其他」）。
- 右上角可以在「行业 / 地区 / 认识场合」之间切换，记住你的选择。默认显示资料填得最全的那一种。
- 没填行业或地区的人单独显示为「未填写」，不混进别的类；人很少时显示提示而不是空图。
- 点小组件进入人脉分析，看完整分布。数据在手机上算，断网也能看。

## 怎么验收

App 计算函数测试（分组、未填写、前几名合并为其他）、组件测试；全量和类型检查；phoneweb 截图（中/日/英、深浅色）。
