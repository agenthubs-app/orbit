# Sprint 0148 — 首页人脉小组件：一眼看到人脉分布

**Plan revision:** 1。**模式:** existing-codebase / single-generator；运行状态以[登记表](../README.md#sprint-登记表)为准。
**原需求:** 用户 2026-11-02 需求 3「首页的人脉小组件要能够展示人脉分布」；协调者自主决定。
**单一目标:** 人脉小组件改为分布视图，复用本机分析计算。
**基线:** 0147 合入后的 `chat-agent`。

## 已确认的事实

- 现在：总数、本月新增、最近 4 个头像（`src/screens/home/HomeWidgetCards.tsx:200-222`），数据来自本机联系人副本。
- 本机已有分布计算：`src/view-models/network-analysis-local.ts` → `api/compute/network-analysis-model`（行业、职级、地区、认识场合）。
- 行业、地区多来自名片推断或手动编辑，未填写比例可能高；`metKind` 可靠（未知归 other）。

## 决定（协调者）

- 三个维度：行业（主行业）、地区（城市，缺失时国家）、认识场合（metKind）。默认选「已填写比例最高」的维度，用户切换后存本机。
- 展示：分段比例条 + 前 3 名 + 「其他」+「未填写」；人数少于 3 显示提示文案。小尺寸组件只显示比例条和第一名。
- 计算复用 network-analysis-model，不新建一套分组规则；颜色取现有设计 token 的分类色。点击进入现有人脉分析页。
