# Sprint 0087 — 没同步过就不要说"暂无"

## 要实现什么

首次进入待办页时，浏览器镜像还在拉取（lease → manifest → 域页约 15–25 秒），页面同时显示"正在同步最新内容…"和"暂无待办／新待办会出现在这里"，计数 0/0。"从未同步"和"同步完确实是空的"是两回事，界面必须分得清。本 Sprint 让镜像快照携带"是否同步过"，并让所有镜像页在没同步过时显示加载态而不是空态。

## 做完能看到什么

- 冷启动进入 `/tasks`：只有"正在同步最新内容…"和骨架／加载态，没有"暂无待办"。
- 同步完成后有数据 → 正常列表；同步完成后确实为空 → 才出现"暂无待办"。
- 同步失败 → 错误态（0078 已有行为，不退化）。
- 其它镜像页（联系人、活动等凡是走 `useSyncedCollection` 的列表）同样不再在未同步时显示空态。
