# PW-0004 — Web 平台能力验证

## 目标

确认 Phone Web 在不触发真实 OCR、外部消息或原生推送注册的前提下，可以安全使用图片／文件选择、分享失败反馈和浏览器通知入口；发现的最小平台差异只在 `.web` 适配层修复。

本目录是 Phone Web 验证编号 PW-0004，与既有 `0004-registration` 业务 Sprint 不同。

## 完成标准

- Web 批量名片选择可读取浏览器 `File`／`blob:`，保留大小、魔数、摘要和上传字节校验。
- 原生 `file://`／`content://` 读取行为不变。
- 图片／文档选择、分享失败、下载能力边界、系统推送开关和收件箱入口有可复核结果。
- 所有真实业务写入、OCR、消息发送和 push-token 注册均保持未执行。
