# Sprint NNNN — 易读标题

本文件是目标模板。新增 Sprint 时填写具体结果，不预填完成声明。

## 要实现什么

用一句话写清谁能完成什么操作、得到什么结果。文档或验收 Sprint 写清交付物及要证明的事实。

## 做完能看到什么

- 列出两到三项具体操作和可观察结果，与 Planner 的范围、SC 一致。
- 写清必要的失败保护；避免只写“优化体验”“完善能力”或堆叠技术缩写。

## 怎么验收

用短段说明需要检查的场景或证据。区分测试、真实业务和设备验证，不把必要检查写成可选项。

完整验收项和启动条件见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；当前状态见[登记表](../README.md#sprint-登记表)，实际执行结束后再记录报告。
