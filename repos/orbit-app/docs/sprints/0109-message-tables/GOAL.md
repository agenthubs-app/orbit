# Sprint 0109 — 用户之间的消息改用三张专用表

## 要实现什么

两个 Orbit 用户之间的消息（「关系沟通」）现在存在万能表里：对话和消息两人共用，信封上没有写「属于谁」。打开收件箱时服务器要翻遍所有人的对话，未读数每 15 秒也要翻遍一次；消息也没法放进手机。本 Sprint 按已定稿的《消息数据方案》把它们搬进三张专用表：对话、对话成员、消息。

## 做完能看到什么

- 收件箱对话列表、未读总数、打开对话翻页、标记已读的结果和现在一样，但读取成本只和「你自己有几个对话」有关，和平台总用户数无关。
- 发消息仍然自带去重：网络不好重发，只存一条。两人同时发，每条消息在对话里的序号连续不重复。
- 撤销关系后，双方都看不到这个对话，服务器上的记录保留。
- App 和网页不需要改：接口返回的内容保持不变。

## 怎么验收

在测试库造大量用户和对话，查询计划走索引、耗时不随总用户数增长；去重、并发序号、未读、撤销、隔离各有真库测试；phoneweb 与 Simulator 上两个账号互发、已读、撤销。
