# Sprint 0092 — IORBIT 首页两块区域别一直转圈

## 要实现什么

IORBIT 首页的"正在读取最近会话"和"正在核对下一步"两块区域长时间停在加载态。本 Sprint 查清这两块各自在等什么，把等待降下来；等不到时给出明确结果（有内容／确实没有／出错了可重试），不再让加载态无限期停着。

## 做完能看到什么

- 进 IORBIT 首页，两块区域在可接受时间内定格为三种结果之一：有内容、确实为空、出错可重试。
- 不再出现长时间停留的加载文案。
- 两块区域的数据来源与耗时被写明。
