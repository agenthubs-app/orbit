# Sprint 0017 — 用真实操作证明主流程跑通，两端数据对得上

## 要实现什么

在同一候选版本验证主要业务流程，并证明资料、联系人授权字段、AI 会话、事项和报名能在 Web 与 App 双向回读。

## 做完能看到什么

- 注册到资料、活动报名和日历，以及名片到联系人、@ 引用、邀请到聊天，都用授权非空样本走通。
- 主办方审核和签到符合角色权限；消息、提醒和推送有实际结果，缺测和失败留在交接中。

## 怎么验收

对五类记录分别完成 Web 写→App 读和 App 写→Web 读，核对同一 ID、版本与内容；加上 Planner 的全量、类型、同步和必要设备验收。这是验证任务，不自动授权新增功能。

完整验收项和启动条件见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；当前状态见[登记表](../README.md#sprint-登记表)，实际执行结束后再记录报告。
