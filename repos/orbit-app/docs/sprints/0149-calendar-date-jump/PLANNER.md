# Sprint 0149 — 日历快速跳到任意年、月、日

**Plan revision:** 1。**模式:** existing-codebase / single-generator；运行状态以[登记表](../README.md#sprint-登记表)为准。
**原需求:** 用户 2026-11-02 需求 4；协调者自主决定。
**单一目标:** 点日历标题打开日期选择并跳转。
**基线:** 0148 合入后的 `chat-agent`。

## 已确认的事实

- 日历 `src/screens/calendar/CalendarContent.tsx`：日/周/月切换（:48-50），前后按钮与今天（:54-56），标题在 :33/:55；`CalendarScreen.tsx:86-87` 处理移动。日历外层 `SwipeSegments` 的横滑用于切 Task 子页，日历内不加横滑。
- 已有日期选择 `src/screens/schedule/PersonalScheduleDateTimePicker.tsx`（含年份网格 `yearJump`、弹窗模式），约 9 处在用。

## 决定（协调者）

- 标题做成按钮（带下拉箭头和无障碍标签），弹出现有选择器的日期模式；不新增依赖、不新造选择器，必要时给选择器加小参数。
- 选择后设置选中日期，三种视图按各自规则定位。
