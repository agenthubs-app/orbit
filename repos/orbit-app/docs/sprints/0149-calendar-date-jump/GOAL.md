# Sprint 0149 — 日历快速跳到任意年、月、日

## 要实现什么

在 Task 的日历里点标题（例如「2026年11月」），弹出日期选择，可以直接选年份、月份和日期跳过去，不用一下一下往前往后翻。

## 做完能看到什么

- 标题旁有一个小箭头，点标题弹出选择器：先看到当月，可以点年份快速换年、换月，再点某一天。
- 选好后日历跳到那一天：月视图跳到那个月并选中那天，周视图跳到那周，日视图跳到那天。
- 「今天」按钮仍然在，一键回到今天。

## 怎么验收

App 定向测试（三种视图下跳转结果）；全量和类型检查；phoneweb 截图。
