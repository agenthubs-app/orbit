# Sprint 0027 — 日程详情与会议记录

## 要实现什么

让用户从日历中的任务、活动、个人日程和会议进入对应详情，并能在会议详情中添加、修改或清空说明。预约会议由参会人共享；没有预约聚合的旧日程会议明确保存为本人私有说明。

## 做完能看到什么

- 日、周、月视图中的每条有效日程都有明确目的地：任务进入待办详情，活动进入活动预览，个人日程进入编辑页，会议进入新的会议详情页。
- 会议详情展示已确认的时间、时区、会面方式、地点和提议上下文；预约参会人可编辑共享说明，旧日程会议可编辑本人私有说明，保存后重新打开仍能读取。
- 保存冲突、网络失败、越权访问或错误响应不会丢失正在编辑的文字，也不会用错误版本覆盖另一位参会人的更新。

## 怎么验收

先用 App view-model／交互测试覆盖四类日程目的地和会议编辑状态，再用 Web service／route 测试覆盖参会人授权、旧记录兼容、版本冲突、幂等重试与清空。完成两端类型、共享契约同步、受影响端全量及 Web 生产构建／重启后，在当前 iOS Simulator 逐类打开日程，并保存、重开同一会议核对说明。
