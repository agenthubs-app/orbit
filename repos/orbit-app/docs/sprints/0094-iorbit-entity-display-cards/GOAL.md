# Sprint 0094 — 对话里五种实体的统一小卡片

## 要实现什么

IORBIT 对话里提到人脉、活动、待办、日程、笔记时，应该出现**同一种规格**的小卡片：认得出这条记录就够了，想看更多点进去。现在是五种各不相同的东西——人脉一个面板、活动一个面板、待办和日程各一个、**笔记什么都没有**——而且人脉那一批还会在正文里被大段文字重复一遍。

这是 0085 设计案「展示」那一半。0085 只做了「写」（草稿卡）和去掉"AI 运行依据"，展示没做；本 Sprint 补上。

## 做完能看到什么

- 问"谁可以帮我引荐餐饮行业的人"→ 出现几张统一规格的人脉卡，点进去到联系人详情；正文不再把同一批人重复列一遍。
- 问待办／日程／笔记／活动 → 同样规格的卡片，点进去到各自详情页。
- 卡片规格一致：类别图标 + 类别名 + 一行标题（超出省略）+ 一行关键属性 + 一行"为什么出现在这里"。
- 笔记从"没有卡片"变成有卡片。

## 怎么验收

五种实体各问一句真实问题，截图对照；正文不再重复卡片已经说过的人；点每种卡片都能到对应详情页。
