# Sprint 0020 — 二级行业能选、能复用，AI 能读取本人的行业资料

## 要实现什么

把行业从一级扩展到二级，让资料、联系人和检索使用同一套分类；AI 需要了解本人时，可调用只读工具获取真实资料和二级行业。现有测试数据也一起补齐。

## 做完能看到什么

- 在 Web 和 App 选择“科技与互联网 → 人工智能与数据”，保存、重开和换端后仍是同一选择；联系人也能使用同一分类，搜索可按二级行业区分结果。
- 对 AI 说“结合我的行业，推荐适合认识的人”，它能调用“读取本人资料”工具，再利用本人二级行业检索，而不是猜测身份或要求重复输入。
- 正常测试资料、测试联系人、关联投影和隔离环境已有测试记录包含有效二级行业；缺字段和旧版本测试反例单独保留，不假装已补齐。

## 怎么验收

检查共享字典和父子关系、两端保存回读、实际 AI 工具调用链及账号隔离，再核对全部测试数据范围、遗漏和补齐结果。只增加下拉选项、提示词或新 seed 数据都不算完成。
