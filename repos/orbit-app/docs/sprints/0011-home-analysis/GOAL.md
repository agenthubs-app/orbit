# Sprint 0011 — 首页按确认的布局展示，分析能看出新旧

## 要实现什么

用户能在已确认的首页布局中查看日程、待办和分析，知道报告何时生成、是否需要更新，并单独修改长期目标。

## 做完能看到什么

- 某个区块加载失败不挡住其他内容；没有推荐时仍可浏览活动，统计可查看明细，已有分析显示时间和版本。
- 打开或刷新页面不自动生成付费分析；用户显式发送后才生成。保存长期目标不覆盖姓名、公司等资料。

## 怎么验收

对照获批首页和 Pipeline 方案检查页面、旧链接与历史访问，再核对分析请求时点及目标保存后的双端回读；显示或隐藏 Pipeline 仍以批准决定为准。
