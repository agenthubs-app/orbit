# Sprint 0117 — 看板和联系人分析在手机上算

## 要实现什么

看板和联系人分析的统计（各种总数、短列表、分布、人脉缺口、跟进机会）只用你自己的数据。0116 之后这些数据都已在手机上，所以 App 可以自己算，不必每次问服务器；断网也能看。网页没有本地副本，继续用 0101/0102 的服务器方案。

## 做完能看到什么

- App 打开看板和联系人分析时，不再请求看板相关接口（AI 分析报告除外），读取量为 0。
- 断网时看板和联系人分析照常显示，标明「截至某时」。
- 手机上算出的每个数字、每个列表与服务器算的完全一致。
- 缺口和机会的计算代码只有一份，服务器和 App 共用。

## 怎么验收

对照测试：同一份数据，App 版、服务器 SQL 版、服务器快照版三者逐项一致；phoneweb 与 Simulator 开飞行模式打开看板与联系人分析。
