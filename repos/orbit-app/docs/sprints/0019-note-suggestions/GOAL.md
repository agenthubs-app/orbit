# Sprint 0019 — 把笔记建议确认成事项，并核对全部需求

## 要实现什么

用户从笔记页用模板进入 IORBIT，发送后生成行动建议，确认建议后只创建一次对应事项；随后把包含笔记在内的全部原始需求逐项验收。

## 做完能看到什么

- 笔记页提供“从这篇笔记整理待办”入口，带上笔记引用并预填 IORBIT；用户可修改请求，发送前不生成建议。
- 建议标明来源笔记、版本和相关联系人，含糊日期先确认；原文改变后旧建议重新校验，拒绝或失败不丢内容。
- 接受结果在笔记、人脉及适用的首页、任务和日历位置一致，两端可回读；多人关联或重试不重复创建。

## 怎么验收

验证模板与笔记引用、发送前零生成、建议来源、确认前零创建、确认后唯一事项及双向回读，再核对 R-00～R-14 的功能、设备、版本、费用和提交证据；任一必需项未满足，都不能宣布全部完成。

完整验收项和启动条件见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；当前状态见[登记表](../README.md#sprint-登记表)，实际执行结束后再记录报告。
