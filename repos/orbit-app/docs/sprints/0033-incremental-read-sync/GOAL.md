# Sprint 0033 — 全域离线读取基础

账号完成首次同步后，断网冷启动仍能读取其离线范围内全部已授权的结构化数据和历史；联网后按域增量更新，并先移除已失去权限的数据。

- 列表、详情、子资源、搜索和聚合入口都从加密镜像读取，包括完整 AI 历史、人脉、消息通知、完整日程、活动角色数据、Agent 可见记录及资料设置。
- 设备只在服务器签发的有限租期内使用上次验证的身份；离线可读不会取得在线写入资格，切账号、服务器、workspace 或权限 epoch 不串数据。
- 未下载、部分完成、过期可读、无权限、锁定和失败各自如实显示；历史未完整下载不能显示“没有结果”。
- 图片、录音、扫描和附件保留加密资源清单，文字不依赖二进制下载；资源可按需读取或明确保留离线。
- 新增角色可补齐历史；实体删除和权限撤销通过各域耐久日志移除镜像及资源。单域重置保留设备草稿和待处理上传数据。

0033 分七个内部阶段交付：覆盖清单；身份/存储；协议/registry；个人/人脉；通信/日程/AI历史；活动/Agent/聚合；资源/搜索/消费者清理。四个旧个人域只是子集，不再是完成边界。

验收以逐入口清单零遗漏、每域授权/分页/删除/撤权/重置测试、真实 SQLCipher 迁移与断网冷启动、同账号 production Web/API→Simulator 回读为准。类型检查或四域通过均不能代替全域完成。
