# Sprint 0051 — 历史笔记可见性与生命周期检查

让用户从写笔记的入口方便地查看自己所有已保存的过往笔记，并确保笔记在创建、编辑、关联、删除、跨端同步和离线读取过程中不丢失、不串账号、不被意外复活。

- 保留首页快速新建笔记，同时提供明确的“所有笔记”入口；从新建、阅读和编辑页面能够安全返回历史列表，未保存内容不会被导航丢弃。
- 默认查看所有已授权、未删除的已保存笔记，支持搜索、关联筛选和完整分页；显示已加载数量与总数，加载失败或仅同步部分历史时不冒充空列表或完整历史。
- 排查旧版笔记、当前 canonical 笔记和旧联系人备注的来源；合法历史数据不因格式升级被静默遗漏，草稿、现场记录与正式私密笔记明确区分。
- 创建或编辑成功后能在列表及另一端回读；删除、撤权、重连和断网重启不会把已删除或无权读取的内容重新展示给用户或新的 AI 检索。
- 提交中文生命周期审查报告，逐阶段列明数据源、存储、接口、版本、失败保护、问题修复及仍未满足的验收。

验收使用超过一页的合法笔记集合、旧格式与当前格式、两个隔离账号，以及同一账号的生产构建 Web/API、PhoneWeb 和主线 Metro 8082 的 iOS Simulator。生命周期依赖缺失必须单列，不能只凭组件测试宣布全部正常。唯一验收契约见 [PLANNER.md](PLANNER.md)。
