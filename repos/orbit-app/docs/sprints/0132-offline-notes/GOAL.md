# Sprint 0132 — 断网也能写笔记

## 要实现什么

在会场没有信号时，也能新建笔记、修改已有笔记。改动先存在手机上，标「未同步」，联网后自动传到服务器。如果同一条笔记在网页上也被改过，手机不偷偷覆盖任何一方，而是把两个版本并排给你看，让你选保留哪一个，或者另存为一条新笔记。

## 做完能看到什么

- 断网时笔记页的「新建」「编辑」可用，提示条写「修改会在联网后同步」；改过的笔记标「未同步」。
- 联网后改动到达服务器，网页上能读到；「未同步」消失。
- 两边都改了同一条时，笔记详情页顶部出现「冲突」选择：保留本机版本、使用服务器版本、另存为新笔记。
- 联网后还有没传完的修改时，AI 页输入框上方写「有 N 项修改还没同步，AI 暂时看不到」。
- 删除笔记仍然不支持（服务器本来就没有这个功能）。

## 怎么验收

「本机数据库扮演服务器」测试里有 A、B 两个账号，验证重复上传只算一次、新建编号替换、冲突两边都保留、别人的笔记不受影响；Simulator 断网写笔记、恢复后在网页读回。
