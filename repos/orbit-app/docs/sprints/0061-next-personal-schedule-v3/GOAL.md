# Sprint 0061 — 独立 Web 个人日程对齐

让 `/app/tasks/personal` 与已交付 App／PhoneWeb 使用同一套个人日程规则：能够设置提醒及重复、查看真实实例、明确修改或取消本次／整个系列，并通过底部选择窗关联已有笔记和人脉。

沿用用户批准的紧凑时间块、线上／线下分段控件、关联 chip 和底部窗设计，不再显示“提醒和重复暂不支持”。打开关联窗立即显示授权列表，可通过姓名、标题和拼音首字母搜索。保存后须独立读取服务器结果，冲突或失败保留草稿。

验收使用当前生产 Web 与主线 Simulator 的同一测试账号、同一明确日程回读，不能只凭组件测试判断跨端一致。提醒真正到期送达、远程 Push 和全域离线仍按原任务分别验证，本 Sprint 不通过改通知配置掩盖它们。
