## 4. 设计过程中发现的线上问题（已排期）

- **笔记可能被覆盖**：笔记的版本比较只在单个服务器进程内做，两台实例同时处理两次编辑时，后写的会覆盖先写的。已列入 `PRODUCTION_ROLLOUT.md` 的已知风险，由 0132 修复。
- **待办删除不比较版本**：删除会抹掉别处刚做的修改。由 0133 修复。
- **消息重传的检查顺序**：先查资格、后查重复。丢了回执时对话恰好被撤销，手机会误以为没送达。由 0135 修复。
- **离线资格表多登记了一行**：登记了服务器根本不存在的笔记删除接口。由 0132 修复。
