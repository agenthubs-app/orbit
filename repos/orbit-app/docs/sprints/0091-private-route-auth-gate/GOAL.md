# Sprint 0091 — 别让人盯着"正在确认登录状态"看六秒

## 要实现什么

进 `/followups` 和 `/contacts/dashboard`，页面停在"正在确认登录状态…"六秒以上才出内容。这不是错误，但六秒白屏在一个已经登录过的账号上说不通。本 Sprint 查清会话就绪为什么要这么久（存储读取、网络校验、还是被别的初始化排在后面），把已登录用户的首屏等待降下来。

## 做完能看到什么

- 已登录状态下进这两个页面，不再长时间停在"正在确认登录状态…"。
- 会话就绪的耗时被量出来，修前修后有对照。
- 未登录时仍然正确跳登录页，登录态判断不因为提速而变松。

## 怎么验收
