# Sprint 0115 — 活动现场放进手机

## 要实现什么

会场常常没有信号。本 Sprint 把「你报名的活动」在现场需要的内容放进手机：活动的地点、时间、介绍（有议程时也放）、你的报名状态、签到开放时间，以及活动方发布给你的座位、桌位和推荐人选。断网时，活动详情页和 0107 做的现场页都能打开看到这些。

## 做完能看到什么

- 报名后，下一次同步就把这场活动的信息和你的报名状态放进手机。
- 活动方发布座位和推荐后，你的那一份同步到手机；别人的座位和推荐不会进你的手机。
- 取消报名或报名没通过后，下一次同步时，这场活动发布给你的座位和推荐从手机上撤下。
- 开飞行模式打开活动详情和现场页，能看到上面的内容，并标明「截至某时」；签到、交换名片等需要联网的操作给出明确提示。
- 活动工作人员能看到的参会者名单等数据不放进手机。

## 怎么验收

「本机数据库扮演服务器」测试里同时有参会者 A、参会者 B 和主办方数据，逐项检查隔离、撤下、增量；phoneweb 与 Simulator 开飞行模式打开活动详情和现场页。
