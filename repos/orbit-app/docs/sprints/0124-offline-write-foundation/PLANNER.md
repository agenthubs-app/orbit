## 已查明的事实（2026-09-28，开工时核对）

- `sync_outbox`（`repos/orbit-app/src/data/sync/local-sync-schema.ts:62-83`）没有状态、类别、依赖列；operation 只允许 create/update/delete。`enqueueOutboxMutation`、`listOutboxMutations`（`local-sync-repository.ts:638`、`:673`）没有产品调用方。
- 本地副本主键是「类别 + 纪元 + 记录编号」，同一记录放不下两个版本；拉取跳过 pending/conflicted 行（`local-sync-repository.ts:192-194`、`:620-624`）。
- 重抄、纪元轮换、单类重置都不动 `sync_outbox`（`:451`、`:554`、`:578`）。
- 清空 = 删库文件和密钥（`sync-lifecycle.ts:141` purge，`:118` eraseOtherIdentities，`:202` suspendScope，`:215` setScope）。触发路径：`AuthSessionProvider.tsx:147`（冷启动被拒）、`:222`（无会话）、`:549`（退出）、`:600`（任何 401 / 复核被拒，经 `:630`、`:671`）。
- 服务器：`auth.ts:68` 调 `isPasswordSessionCurrent`（`features/auth/session-revocation.ts:5-11`），数据库出错时抛错，Auth.js 返回空会话，手机按 0127 规则当成拒绝。
- 触发同步的原因只有 mount/explicit/foreground/invalidated（`sync-freshness.ts:6-10`）；断网时每 10 秒复核登录（`AuthSessionProvider.tsx:93`）。

## 范围与文件

1. **队列表升级**（本地迁移，原生）：`sync_outbox` 增加 domain_id、state（queued/sending/conflict/failed）、request_json（完整请求体，首次尝试后冻结）、depends_on、attempt_count、first_attempt_at、server_snapshot_json；operation 扩为 create/update/delete/complete/reopen/cancel/send。新表 `sync_aliases`（local_id → canonical_id，保留 30 天）。队列不绑纪元，只绑本库的「服务器 + 账号」。
2. **叠加读取**：本地副本只放服务器内容；提供「服务器版本 + 队列中未确认修改」的叠加读取接口和按类别的待上传计数。本地副本行的 `sync_state` 对这些类别恒为 synced。
3. **上传执行器**：单飞；顺序为「在线确认 → 上传 → 拉取」；同一记录 FIFO、最多 4 条并行、依赖等被依赖者确认；每条一个请求；回应分类与重试参数按设计案第 8 步（全随机退避基数 1 秒、上限 60 秒，Retry-After ≤ 5 分钟，每条每轮 ≤ 5 次，每轮 ≤ 30 秒，到限保留）。确认后一个本地事务内完成：写本地副本、记别名、替换依赖行里的临时编号、删队列行。从未尝试上传的同一记录修改合并。
4. **上传时机**：冷启动在线确认后、回前台、网络恢复（离线复核成功的那一刻）、通知点击（跳转前）、入队时在线、前台 15 秒周期、手动重试。断网身份模式下不上传。
5. **保险箱**：所有清空路径在队列不空时，先把队列与别名写进按「服务器 + 账号」加密的独立文件（密钥在 SecureStore），读回核对条数与指纹后才写待清理标记并删除本地库；写失败则不删库、锁住并提示。同一账号打开新库时一个事务放回队列并删保险箱。登录页提示与「登录其他账号 / 放弃」确认；退出时的三选项确认；30 天到期删除。
6. **服务器账号状态接口**：只回答 active / disabled / password_changed，数据库出错回 503。手机收到空会话时先问它，只有明确的停用或改密才算拒绝。
7. **测试专用类别**：只在测试里注册的一个 kind，用内存或本机 HTTP 假服务器模拟 2xx/409/404/422/5xx/429/401，验证执行器；不进产品资格表。
- 排除：任何产品类别开放断网写（0132 起）；浏览器版断网写（设计案 D2）；服务器新批量接口（D1）。
