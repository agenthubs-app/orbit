# Sprint 0053 — 个人日程新建、编辑与查看设计

按用户提供的参考图，重做个人日程设置和详情界面，让标题、日期、起止时间和地点清楚易用，保存后能从日历打开独立详情并安全修改。

- 大号底线标题输入；日期、起止时间合并为一个时间块，提供30分钟、1小时、2小时和真正的全天选项；跨天时才出现结束日期，时区放在时间块附注。
- 地点支持线上／线下；会议链接可选填写，只有合法已保存链接才显示“进入会议”。保留日程删除、失败保稿和版本冲突保护。
- 详情采用大标题、大时间数字和紧凑信息行，提供编辑／改期；日历、首页及个人日程列表打开同一条真实记录。
- 关联人脉和笔记使用当前账号的真实可访问对象，支持选择、移除和跳转，不平铺人脉全集，不自动向其他用户分享。
- 提醒和重复如尚无实际执行能力，明确说明暂不支持，不能显示虚假的“开始前15分钟”或提供保存后不生效的选项；外部Calendar/Gmail/OAuth继续按既有决定后续处理。

验收包括参考图同屏状态对照、保存及重开、改期／跨天／全天、合法会议链接、关联对象、409和换号保护，以及同版本生产Web/API、PhoneWeb和主线8082 Simulator同记录双向回读。计划或截图不是已实现声明。唯一契约见 [PLANNER.md](PLANNER.md)。
