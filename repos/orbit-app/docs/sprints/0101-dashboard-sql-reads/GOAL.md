# Sprint 0101 — 看板改为数据库算

## 要实现什么

看板和「联系人分析」每次打开，都把你名下 6 类数据全部读到服务器再算统计，还把四个完整列表整份返回给手机。本 Sprint 把能用数据库直接算的部分（总数、短列表、分布）改成只返回结果；联系人分析不再读完整联系人列表；App 登录后默认页改回首页。

## 做完能看到什么

- 看板和联系人分析显示的数字、列表与改前完全一致（对照测试逐项比较）。
- 每个短列表只返回前 5 条和页面要显示的字段。
- 联系人分析只按编号读取页面上出现的联系人。
- App 登录后（没有指定跳转目标时）进入首页 `/home`。

## 怎么验收

对照测试：同一份数据，SQL 版与现有代码版结果逐项一致；读取成本账本记录改前改后。
