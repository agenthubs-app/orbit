# Sprint 0049：报名选择题简化与活动画像连续填写

报名资料不用在每组选项下面重复显示输入框；活动画像按顺序保留已回答的问题，并让用户知道已经填写多少、何时可以先停下来。

具体可见结果：

- 每道有选项的问题最后有一个“其他”。选择普通选项时只显示选择结果；选择“其他”才展开填写入口。原来没有选项的开放题仍可直接填写。
- 活动画像回答第一题后，第一题与答案留在上方，第二题追加在下面；继续作答时重复这个过程。请求失败不会清空已答内容。
- 画像标题下显示：“多回答几题，能让你在这场活动中的定位更清楚。核心信息填完后，可以先生成画像，也可以继续补充。”
- 显示“核心信息 2/2 · 信息覆盖 2/8”等实际填写进度。核心信息齐全时提示“可以先生成画像”，不是强制完成所有选填项，也不是声称画像准确率达到某个百分比。

Web（含手机 Web）和 Simulator 实际验证选择、其他填写、连续两题、失败恢复及进度变化。已报名不可修改、审核申请必答和其他服务端资格不变。唯一验收契约见 [PLANNER](PLANNER.md)。
