# Sprint 0133 — 断网也能管待办

## 要实现什么

断网时可以新建、修改、完成、重新打开、取消和删除自己的待办。和笔记一样，改动先存在手机上、联网后上传。删除比较特殊：如果你在手机上删了一条待办，而它同时在网页上被改过，手机会先把网页上现在的内容给你看，再问你是否仍然删除，不会直接抹掉别处的修改。

## 做完能看到什么

- 断网时待办页的六种操作都可用，改过的行标「未同步」。
- 联网后改动到达服务器；完成、重新打开、取消直接生效，不会和别处改的标题、备注冲突。
- 删除冲突时出现「仍然删除 / 保留」的二次确认。
- 接受待办建议、让 AI 生成待办、关系跟进的「完成并记录结果」仍然需要联网。

## 怎么验收

「本机数据库扮演服务器」测试里有 A、B 两个账号，验证重复只算一次、删除冲突、别人的待办不受影响；Simulator 断网操作、恢复后在网页读回。
