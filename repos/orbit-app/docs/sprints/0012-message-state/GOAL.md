# Sprint 0012 — 消息及时更新，角标和点开的内容都正确

## 要实现什么

用户留在 App 前台时能及时看到新消息，已读和提醒状态可靠保存，点消息能到当前账号有权访问的内容。

## 做完能看到什么

- 列表、会话和角标在批准时效内更新；重开或换端后计数一致，断网恢复不重复消息、不丢未发送草稿。
- 删除、过期或无权限目标有明确提示；推送遵守通知偏好和系统权限，登出或换号后旧内容不再出现。

## 怎么验收

用授权双用户检验持续前台收发、已读回读和合法跳转；实体设备还须验证推送接收、设备注册与解绑。
