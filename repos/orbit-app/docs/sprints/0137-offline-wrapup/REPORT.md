## 3. SYNC_CLEANUP_STATE_FAILED 的根因

- **是环境问题，不会锁住正式版用户。**
- worktree 的 `node_modules` 是符号链接。Debug 版的 Metro 会把 `expo-crypto`、`expo-secure-store` 拆成单独的分块，分块地址里带 `/../`，被网址规范化后 Metro 找不到文件，返回 404。`prepare()` 把这个错误当成「清理失败」，于是挡住了登录。
- Release 版不拆分块，所以不受影响。
- **修复**：带入 0124 的 `metro.config.js`（`a59c7215b`）。
- **加固**：
  - 清理被拒时上报步骤、错误名、错误码和一条打码的提示（`ada5a088f`），以后能直接看出原因；
  - 格式坏掉的清理标记会在清除其他账号之后作废，不再让用户永远登不上；同时保留 0124 对待同步写入的保证（`f1a5984e2`）。
