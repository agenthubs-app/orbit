# Sprint 0137 — 离线收口：关系推进看板、联系人详情、真机补测

## 要实现什么

0131 完成全 App 页面离线清单后，协调者复核时发现，还有几处和用户「我需要这些离线也能看」的要求不符：

1. **关系推进看板（`/contacts/pipeline`）被标成了「只能在线」。** 它只是你自己联系人的关系阶段，数据 0116 已经放进手机了，应该在手机上计算、断网也能看。
2. **联系人详情（0116 做的页面）断网时有两个问题**：没有离线提示；关系区直接显示原始错误 `ORBIT_APP_NETWORK_ERROR`。
3. **打开别的账号的内容时**（比如另一个账号的 AI 会话或联系人），断网显示「服务器连不上」，应该显示「还没保存在这台设备上」。
4. **0131 在模拟器上没覆盖到的页面**要补测：
   - 待办详情的最终版本；
   - 收件箱来源、联系人列表、关系图、个人待办；
   - 笔记和日程的编辑页、新建页；
   - 未登录状态下的 5 个页面断网时显示「需要联网」。

## 做完能看到什么

- 断网打开关系推进看板，能看到按阶段分好的联系人，数字和联网时服务器给的一致，并显示「截至」。
- 断网打开联系人详情，顶部有「截至」提示条，关系区显示本机内容或「需要联网」，不再出现原始错误码。
- 页面离线清单里，关系推进看板改为「本 Sprint 实现本地优先」，审计测试通过。
