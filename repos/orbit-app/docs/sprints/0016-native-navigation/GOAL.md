# Sprint 0016 — 确认手机上能顺利进出页面、看清并操作

## 要实现什么

在实际设备上验收导航、字号、键盘和辅助功能，确认主要操作可达，并明确记录设备相关缺项。

## 做完能看到什么

- 冷启动、四个根页面、IORBIT 开关、深链、登录回跳和无历史返回都有可复现结果。
- 浅深色、三语长文、大字号及运行中字号切换不挡操作、不丢草稿或焦点；VoiceOver、实体 iPhone 和 Android 返回各有独立结论。

## 怎么验收

按 Planner 收集对应 Simulator、实体设备和辅助功能证据。缺设备就记受阻；发现需改原生补丁时先按原审批处理，本 Sprint 的验收目标不代替修改授权。

完整验收项和启动条件见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；当前状态见[登记表](../README.md#sprint-登记表)，实际执行结束后再记录报告。
