# Sprint 0066 — 活动报名与活动画像 7a 改版

按用户提供的 7a 三张设计稿重做报名资料、画像追问和画像结果，让选择题、历史回答和画像成品更清晰，并确保每个显示的操作都有真实行为。

- 报名资料采用白底、发丝线分区、紧凑选项；仅选择“其他”才显示一行底线输入。
- 活动画像拥有独立追问和结果视图；当前问题突出，过去的回答保留为紧凑复核表，可查看全部。
- 报名、取消、再次报名保持现有真实资格和确认流程，不由设计稿中的示例状态决定。
- 补齐已获批准的历史答案编辑和独立画像保存：保存画像不改变报名状态，画像本人可读，其他人中仅有权限的主办方可读。

验收包含实际 Phone Web 和主线 Metro 8082 的 Simulator 交互、保存后重开回读、权限反例与底栏不遮挡。源码须提交并合入 `chat-agent`，通过合并树验证后普通 push；只完成设计、预览或局部测试不算完成。
