# Sprint 0060 — 个人日程提醒与重复真正生效

让用户在个人日程中设置提醒和重复规则，保存后可回读、按规则出现后续日程，并在正确时间获得提醒。

- 提醒支持不提醒、开始时、提前5／15／30分钟、1小时和1天；修改时间或取消日程同步更新未来提醒。
- 重复支持不重复、每天、每周和每月，可设结束日期；支持明确编辑／取消本次或整个系列，不悄悄修改所有日程。
- 沿用日程时区，正确处理跨日、全天、夏令时和月底；新设置在Web/API与App间一致。
- 不重复投递，不把模拟器通知或API测试冒充真实远程Push已经验证。

通过真实保存重开、重复实例、改期／取消和到期提醒的操作链验收；同时将控件接入0059参考设计。真实远程Push环境缺项单列，不阻止实现和验证应用内提醒。
