# Sprint 0013 — 账号、首页和设置能用中日英操作

## 要实现什么

用户可按已确认的语言策略，用中文、日文或英文完成账号、资料、首页和设置中的原有操作。

## 做完能看到什么

- 按钮、错误和状态跟随界面语言，服务端原文保持不变；缺失或无效语言按统一规则回退。
- 切换语言不丢输入、登录身份或返回目的；长翻译和大字号下仍能操作，日期时区口径不变。

## 怎么验收

在三种语言下实际操作本组页面，检查草稿、换账号、长文布局与日期不变量，再做必要原生核对。
