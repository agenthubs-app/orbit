# Sprint 0119 — 用户之间的消息放进手机

## 要实现什么

0109 把用户之间的消息搬进了对话、对话成员、消息三张表，成员表上写着人。本 Sprint 把你的对话和全部历史消息放进手机：收件箱和聊天页先读本地，断网也能翻看历史；撤销关系后，这个对话从双方手机上删除。

## 做完能看到什么

- 断网时能看对话列表、未读数和每个对话的全部历史消息，标明「截至某时」；发送提示需要联网（断网发送在 0120 之后）。
- 新消息到达后，下一次同步只传新消息和变化的未读数。
- 撤销关系后，双方手机上的这个对话和它的消息在下一次同步时被删除。
- 第三个人的对话不会进你的手机。

## 怎么验收

「本机数据库扮演服务器」测试里有 A、B、C 三个账号，逐项检查隔离、增量、撤销后删除；phoneweb 与 Simulator 开飞行模式打开收件箱与聊天。
