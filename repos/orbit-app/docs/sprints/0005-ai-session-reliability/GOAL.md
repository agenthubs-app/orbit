# Sprint 0005 — AI 重试不重复生成，换端续聊不丢历史

## 要实现什么

用户遇到超时或保存失败时能明确恢复，并能在 Web 和 App 之间接着聊，保留已有消息。

## 做完能看到什么

- 打开会话或切回前台不会自动发问；重复提交得到同一请求结果，仅重试保存时不重新生成。
- 换端后消息顺序和必要信息仍在；切账号或会话不串历史，失败时保留输入。

## 怎么验收

分别验证请求去重、超时恢复和双向续聊；真实生成证据、首次 503 的原因与处理结论也须满足 Planner，不能靠一次成功跳过未解决问题。
