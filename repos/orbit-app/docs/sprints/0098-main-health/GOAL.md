# Sprint 0098 — 让主线两端全量重新可验收

## 要实现什么

同步 Li-QY 在 2026-09-24～27 推送的提交后，App 全量里有 81 条以上失败，orbits 全量会被一个测试卡住跑不完。规则要求每个 Sprint 两端全量通过，所以在这之前，后面所有 Sprint 都无法验收。

本 Sprint 把两端全量修回可验收状态。

## 做完能看到什么

- App 跑一次全量，除了登记在案的环境类失败外全部通过。
- orbits 全量能跑完，不再挂起；失败数不高于已分类的既有失败。
- 每一条修复都说得出原因：是测试过期、还是产品代码真坏了。

## 怎么验收

干净工作区各跑一次两端全量，对照报告里的失败清单逐条核对。

完整验收项见 [PLANNER.md](PLANNER.md)。
