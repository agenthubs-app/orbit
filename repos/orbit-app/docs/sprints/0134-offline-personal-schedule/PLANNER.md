## 已查明的事实（2026-09-28，开工时核对）

- 服务器日程去重：收据在 `personal_schedule_mutations`，先查收据再比 `expectedUpdatedAt`（`repos/orbits/features/personal-schedule/service.ts:131-158`）；事务内按账号取锁（`withScheduleTransaction`，`:109`）；新建编号 = 账号 + idempotencyKey（`:247`）。
- 保存时生成提醒计划并投影到收件箱（`:91-107`，窗口从服务器当前时间开始）。
- 重复日程要求 scope（occurrence / series），单次修改写例外（`:154-165`）。
- App 资格表已登记日程新建、编辑、删除为 `offline_queue`（`repos/orbit-app/src/api/schema/offline-policy.ts:43-45`）。

## 范围与文件

1. **App 资格表与资格判断**：只有不重复、kind 为 personal 的日程可以断网编辑和删除；重复日程、约见、共享会议断网提示需要联网。
2. **App 日程页**：列表、详情、编辑表单叠加读取；新建、编辑、删除断网可用；「未同步」「冲突」「未能保存」；删除冲突复用 0133 的二次确认。
3. **跨类依赖**：日程的 `noteIds` 引用 `local:` 笔记时，日程修改依赖那条笔记新建；笔记确认后在发送前替换；笔记新建永久失败时日程标失败并说明原因。
4. **服务器核对**：断网新建、提醒时间已过的日程上传后，不生成立即触发的过期提醒（若现状会补发，则在提醒计划里跳过 fireAt 早于服务器当前时间的项，并加真库测试）。
- 排除：重复系列与单次修改；约见；浏览器版断网写。
