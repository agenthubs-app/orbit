# Sprint 0136 — 断网写全链验收与历史收口

**Plan revision:** 1。**模式:** existing-codebase / single-generator。运行状态只在登记表。
**原需求:** 0120 断网写设计案第 11 步检查表、决定 D10（冲突频率统计后再议自动合并）、D14（单独一期）；0120 PLANNER「失败与交接」（历史 0034 状态回写）；历史 0035 SC-03（启动、后台、断网、通知点击恢复）、0036 SC-03（pending/冲突/失败提示）。
**单一目标:** 四类断网写在组合意外情况下通过同一张矩阵，并回写历史 0034–0036 的登记状态。
**易读目标:** [GOAL.md](GOAL.md)。
**基线:** 0135 合并后的 `chat-agent`（开工时追加提交号）。
**进入条件:** 0124、0132–0135 已合并。

## 范围与文件

1. **组合矩阵测试**（新测试文件，真库 + App）：四类同时有待上传时，分别经历杀进程、冷启动断网、恢复网络、冷启动被拒、运行中 401、账号状态接口 503、退出、登录其他账号（确认删除）、同账号重新登录、保险箱 30 天到期、离线读取租约过期、注册表版本升级（整类重抄）、纪元轮换。每格断言：不丢、不重复、不串账号、界面状态正确。
2. **上传时机**：启动、回前台、网络恢复、通知点击四个入口各一条端到端测试（承接 0035 SC-03）。
3. **AI 提示**：四类各有待上传时 AI 页提示的类别与数量；队列清空后消失；换账号立即清空旧提示（承接 0036 SC-03）。
4. **冲突统计**：只在本机开发库上统计一轮 QA 使用中的冲突次数与类型，写进报告，供 D10 决定；不上传任何遥测。
5. **文档**：更新登记表中 0034、0035、0036 的状态说明；必要时修正设计案中的行号引用。
- 排除：新功能；浏览器版断网写（D2 另议）。
