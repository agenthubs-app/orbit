# Sprint 0110 — 普通问答不再写运行记录

## 要实现什么

0103 之后，问 AI 一次仍会写一条「运行记录」。运行记录只在 AI 要执行动作时才有用（动作状态、失败重试、撤销）；普通问答的全部信息已经在请求记录里，运行记录没有任何读取方。本 Sprint 让普通问答只留请求记录。

另外清掉每次问答里的一处浪费：为了统计「查过多少条数据」，服务器会把工具涉及的整类数据全部读一遍只为数个数。

## 做完能看到什么

- 普通问答后，数据库只多一条请求记录，没有运行记录。
- 用户等回复的时间里，不再包含写运行记录的数据库往返。
- AI 执行动作时仍写运行记录，动作状态卡和 Agent 账本照常。
- 每次问答不再为计数整类读取数据。

## 怎么验收

真实问答前后数据库计数；请求耗时前后对照；带动作的问答验证状态卡与账本；读取小票对照。
