# Sprint 0122 — Codex 第二轮审阅：修复剩下的问题，补上原生证据

## 要实现什么

2026-09-27，Codex 在各 Sprint 的 `codex-review.md` 里追加了「给 Claude 的后续处理清单」。其中大部分已经排进后续 Sprint，或属于需要用户授权的生产验收。剩下几处需要立刻修，其中有 2 个 P2 缺陷出在 0104：

- 草稿保存到一半时继续编辑，第一次保存的回执迟到，会把第二版也标成「已保存」；
- 收件箱跳过不认识的通知时，把本来就不算未读的条目也从未读数里扣掉了。

另外还有：通知筛选没有告诉读屏软件当前选中的是哪一项；Agent 账本的界面还不能翻页；0103 留下一条跟当前时间有关的测试会失败；几个 Sprint 的原生（Simulator）验证没有做。

## 做完能看到什么

- 保存草稿时继续打字，新写的内容保持「未保存」；保存过程中切换对话或账号，旧的响应不会影响新的状态。
- 收件箱遇到不认识的通知时，未读数仍然正确。
- 通知筛选的选中状态能被读屏软件识别。
- Agent 账本能在界面上翻到下一页；页末不会把「本页条数」说成「全部条数」。
- 0098–0104 缺的 Simulator 验证全部补齐，逐项留下证据。

## 怎么验收

每个缺陷先写一条会失败的测试，修复后通过；Simulator 上逐项走一遍并截图；两端全量无回归。
