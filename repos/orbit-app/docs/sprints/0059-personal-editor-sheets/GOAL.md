# Sprint 0059 — 个人日程编辑设计还原与关联选择窗

按用户提供的项目包还原个人日程编辑页，并让关联笔记、人脉点击后立即出现可搜索、可选择的底部弹窗。

- 标题、时间卡、时长快捷键、线上／线下切换、联系人标签、紧凑设置行和固定保存按钮按参考布局实现，不再用大间距通用表单近似。
- 底部弹窗先展示当前账号已有资料，支持分页、选中／取消、名称搜索和首字母匹配；无资料、加载失败也有明确反馈。
- 选择保留在日程草稿中，保存成功后重开仍存在；取消编辑不写入。私有关联不自动分享给联系人。

使用同尺寸、同内容截图对照，并在真实 Web/API 与 Simulator 上验证弹窗、选择、保存重开和取消。提醒、重复的真实执行由追加 Sprint 0060 完成，不能用静态选项冒充支持。
