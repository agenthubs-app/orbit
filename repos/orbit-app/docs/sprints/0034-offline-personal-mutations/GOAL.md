# Sprint 0034 — 个人数据离线写入与冲突处理

## 要实现什么

让用户在断网时仍可新建、编辑或删除笔记、待办、已确认跟进和个人日程；操作先持久保存为待同步，联网后按顺序幂等提交，冲突时保留双方版本供用户处理。

## 做完能看到什么

- 断网保存后页面立即显示“仅本机，等待同步”，重启 App 仍能看到，且不会声称 Web 或 AI 已经收到。
- 恢复网络后相同操作只在服务器生效一次；服务器回执把临时 ID/revision 原子替换为 canonical 值。
- 同一记录在别处被改过时不静默覆盖：用户能比较本机草稿与云端版本，选择保留本机、使用云端或另存副本。
- 邀请、报名、共享 meeting、权限、账号删除和 AI 外部动作断网时明确不可用，不进入离线队列。

## 怎么验收

以 outbox 状态机和四域 mutation adapter 的 RED→GREEN 测试覆盖重启、重放、乱序、网络抖动、永久错误、账号切换和冲突。再让 Simulator 离线创建/修改四类记录，恢复网络后从 Web 回读同一 canonical revision，并验证 AI 在同步前看不到、同步后才可读取。
