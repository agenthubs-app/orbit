# Sprint 0034 — 按风险开放离线写入

让用户断网时确认保存笔记、个人任务、已确认人脉跟进和个人日程，重启后仍看得到待同步内容，联网验证权限后只提交一次，并由用户处理冲突；同时为全域离线读取提供明确的缓存与写入策略。

- 全部可离线读不等于全部可离线写。邀请、消息发送、报名、共享会议、权限、账号删除、provider、扫描/导入执行和 AI 外部动作仍需在线，未登记动作在入队前拒绝。
- 保存后显示“仅本机，等待同步”；失败和冲突保留输入，云端确认前不声称 Web 或 AI 已收到。
- 重连先验证身份和权限、清理失去资格的投影，再上传获准操作；冲突可使用云端、明确保留本机或在领域允许时另存副本。
- 页面/API 的读取持久化、写入和二进制策略分别登记。临时快照拒绝秘密字段、超限数据和内嵌文件；图片/附件按需或明确保留离线，并单独加密。文件未下载不影响已同步文字读取。

验收覆盖四域持久化、服务器事务回执、重放/冲突/隔离、策略拒绝以及快照与二进制资源安全，再以同账号 Web/App 回读和 AI 同步前后可见性证明真实行为。0033 提供身份、读取 registry、游标和资源 manifest；本线不重新定义这些契约。

唯一验收契约见 [PLANNER.md](PLANNER.md)，设计见 [DESIGN.md](DESIGN.md)。目标是预期交付，不表示实现已完成。
