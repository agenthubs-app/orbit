# Sprint 0125 — 浏览器版 App 断网也能看笔记

## 要实现什么

0108 之后，原生 App 断网能看笔记和个人日程；浏览器版（phoneweb）只有个人日程和待办能离线看，笔记仍然只能在线看。原因是 0077 的威胁模型把笔记排除在浏览器本地镜像之外：浏览器里同源脚本可以借用密钥解密。那份文档写的是「留待第二批评估」。

**用户 2026-09-27 决定放开**：浏览器版也把笔记放进本地镜像。

## 做完能看到什么

- 在浏览器版打开笔记列表和详情，先显示本地副本，再后台同步；断网时显示「截至」，新建和编辑提示需要联网，和原生一致。
- 换账号、换服务器、清除站点数据、撤权时，笔记副本和待办一样被清掉。
- 威胁模型文档更新：笔记改为「是」，写明用户决定、接受的风险（同源脚本可解密笔记正文）和已有的缓解措施。

## 怎么验收

浏览器测试覆盖落盘加密、换账号清除、撤权清除；phoneweb 双账号断网截图；两端全量无新增失败。
