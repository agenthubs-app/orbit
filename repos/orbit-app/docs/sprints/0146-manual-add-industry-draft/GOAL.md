# Sprint 0146 — 手动添加：公司、行业、自动保留草稿

## 要实现什么

手动添加联系人时，公司和行业可以直接填；填到一半离开页面，下次打开还在。

## 做完能看到什么

- 手动添加页一打开就有「公司」输入框（输入时提示已有公司名），下面有「行业」，点开用和编辑联系人相同的行业选择。
- 保存后，联系人详情里能看到公司和行业；人脉分析里这个人归到所选行业。
- 填了一半返回或退出 App，再进手动添加，内容自动恢复，并提示「已恢复上次未保存的内容」，可一键清空；保存成功后草稿删除。草稿只存在这台设备上，按服务器和账号区分。

## 怎么验收

App 与服务器定向测试（行业写入、草稿恢复与清除、换账号不串）；两端全量和类型检查；phoneweb 运行截图。
