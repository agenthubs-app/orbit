# Sprint 0129 — 交换名片的通知进 App 收件箱

## 要实现什么

0127 在本地跑通后台 worker 后发现：活动现场交换名片后，worker 确实生成了「对方申请交换」「对方已接受」两条通知，网页旧接口 `/api/notifications` 能读到，**但 App 收件箱的「通知」读的是新收件箱，名片交换的通知只写进了旧的通知表，两边没有接上**。结果是 App 用户交换名片后收不到任何通知。

## 做完能看到什么

- 活动现场有人向你申请交换名片、或接受了你的申请，App 收件箱「通知」里出现对应条目，点开进入现场页的资料面板或新联系人。
- 未读数、全部已读、网页端显示都与新收件箱一致；旧通知表里已有的这类通知按规则迁入或在读取时合并，不重复。
- 其它仍只写旧通知表的通知类型一并列出，能接的接上，不能接的写明原因。

## 怎么验收

用 0127 的本地 worker 脚本真实跑一次交换，Simulator 收件箱出现通知；真库测试覆盖去重与已读。
