# Sprint 0008 — 确认对方身份后，真正发出并收到消息

## 要实现什么

用户通过服务端验证的邀请和身份绑定，与具备聊天资格的对方完成真实收发。

## 做完能看到什么

- 邀请链接可预览、复制或系统分享，打开页面不会自动发邀请；对方接受并绑定后，刷新显示可聊天。
- 只有真实投递回执才显示发送成功；失败保留输入，重试不重复投递，撤销资格后不能继续发送。

## 怎么验收

用获授权的两个用户验证邀请、绑定、收发、重开与双端回读，并检查撤权和切账号隔离；草稿预览不算发出消息。
