# Sprint 0018 — 一份笔记关联多人，内容和隐私都保留

## 要实现什么

用户写一份独立笔记并关联多位联系人，从不同人脉详情打开的都是同一份正文和版本。

## 做完能看到什么

- 解除某一联系人关联不删除正文或其他关联；越权访问被拒绝，失败和版本冲突保护草稿。
- 确认新入口和旧内容可访问后再关闭旧互动写入口；资料备注及合法字段仍能编辑，旧内容不被强制归类或删除。

## 怎么验收

验证同一笔记的编辑、关联解除、权限和冲突，并核对 Web/App 双向回读及旧入口切换前后的原文与所有者。
