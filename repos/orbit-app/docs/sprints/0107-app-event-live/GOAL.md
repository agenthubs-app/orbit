# Sprint 0107 — App 里的活动现场页

## 要实现什么

活动当天，网页上已报名的参会者可以打开「现场」页 `/events/[id]/live`：签到、看为你推荐的人、全部参会者、桌位与轮次、关系图和议程，并直接发起交换名片、记笔记、约时间。大家在现场用的都是手机，App 里却没有这个页面，只有分散的「参会者与名片交换」和旧的派对模式。本 Sprint 把活动现场页做进 App。

这是界面改动：**先出设计案给用户批准，批准后才写代码。**

## 做完能看到什么

- 已报名的参会者在 App 的活动详情里能进入「现场」，看到与网页相同的几个分区。
- 签到、交换名片（发起、回应、撤回）、记一条相遇笔记、约时间，都能在现场页完成。
- 没报名的人进不了现场页，会看到明确提示。
- 这个页面也是后面「活动现场放进手机」（0115）让它断网可用的基础。

## 怎么验收

设计案经用户批准；phoneweb 与 Simulator 上用已报名和未报名两个账号各走一遍；与网页现场页对同一活动显示相同的内容。
