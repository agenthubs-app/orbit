# Sprint 0003 — 补完资料后，回到原来要办的事

## 要实现什么

新用户能完成注册和必要资料补全，然后回到原活动或页面；资料完整的用户不被重复拦截。

## 做完能看到什么

- 行业和职位按已批准的选项填写，可选内容仍可自填；提取的信息经本人确认才保存。
- 保存失败、刷新或冲突时草稿受保护；切账号不串资料，App 和 Web 能读到同一用户的保存结果。

## 怎么验收

覆盖缺项与完整用户、合法与非法返回目标，并在获授权环境验证注册、Google 系统回跳和双端资料回读。

完整验收项和启动条件见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；当前状态见[登记表](../README.md#sprint-登记表)，实际执行结束后再记录报告。
