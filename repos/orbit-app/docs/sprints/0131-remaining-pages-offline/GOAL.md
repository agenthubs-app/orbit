# Sprint 0131 — 其余常用页面断网也能看

## 要实现什么

用户 2026-09-28 要求：「我需要这些离线也能看」。

协调者逐个页面核对后发现，0115–0119 覆盖了活动（已报名）、联系人、看板、通知、AI 会话、消息，但以下常用页面**没有任何 Sprint 负责**，断网时仍然打不开：

- 首页（今日待办、日程、推荐活动、收件箱角标的汇总）
- 自己的个人资料和资料预览
- Agent 动作中心、All Actions 账本
- 关系待办、待办建议、今日、跟进
- 约谈详情
- 活动列表和推荐活动（包括没报名的公开活动：显示最近一次看到的列表）

本 Sprint 把这些页面都改为「先读本地、后台同步」，断网时显示「截至」，写入入口提示需要联网。同时输出一张**全 App 页面离线清单**，每个页面要么能断网看（写明由哪个 Sprint 实现），要么明确只能在线（写明原因），不留没有归属的页面。

## 做完能看到什么

- 断网时打开首页、个人资料、Agent 账本、关系待办、今日、跟进、约谈详情、活动列表，都能看到上次同步的内容和「截至」提示。
- 恢复联网后自动补同步，不会整库重拉。
- 只能在线的页面（例如登录、管理后台、主办方运营、名片识别、向 AI 提新问题）断网时显示清楚的「需要联网」，而不是报错页。
