## 范围

1. **全 App 页面离线清单（先做）**：对 `repos/orbit-app/app/` 下每个路由，列出它读哪些接口、断网表现、归属。归属分三种：
   - 已由某个 Sprint 实现本地优先（写 Sprint 编号，并实测断网能看）；
   - 本 Sprint 实现；
   - 只能在线，写明原因（例如需要服务器实时计算、涉及凭据、管理员工具、付费 AI、主办方实时运营）。
   不允许有没有归属的页面。清单写进 `docs/offline/page-inventory.md`，并加一条审计测试：新增路由必须登记归属。
2. **本 Sprint 实现的页面**（沿用注册表 v2 和同步机制，必要时新增同步类别，并过一遍 0077 威胁模型）：
   - 首页：各卡片读本地副本（待办、个人日程、已报名活动、收件箱角标用本地通知未读数）。推荐活动显示最近一次同步的结果。
   - 自己的个人资料、资料预览、标签：读本地副本。编辑需要联网。
   - Agent 动作中心、All Actions 账本：本地保存最近若干页（数量写明理由），可以断网浏览。确认、撤销需要联网。
   - 关系待办、待办建议、今日、跟进：读本地副本。
   - 约谈详情：读本地副本。
   - 活动列表和推荐：保存最近一次看到的公开活动列表（公开数据，不按用户归属），断网显示「截至」。
3. **只能在线的页面**：断网时统一显示「需要联网」的空状态，不出现报错页或空白页。
4. **浏览器版（phoneweb）**：同样覆盖，每新增一个进入浏览器镜像的类别，都要在威胁模型里写明，并按 0125 的规则处理。
- 排除：断网写（0120+）。

## 协调者追加范围（2026-09-28，来自 0115，协调者按授权决定）

- 从日历点活动时进入的是 `/schedule/events/:id` 预览页，这个页面没有本地副本，断网时仍会报错。**决定：日历里点已报名的活动，改为进入 `/events/:id`**（0115 已支持离线）；预览页本身也补上离线状态，或者跳转过去。
- 取消报名后断网打开活动详情，页面上同时出现红色的「暂时取不到活动详情」错误框和「已从本机移除」。**决定：本机有取消或被拒的状态行时，显示中性的状态说明加一个返回按钮，不显示错误框。**
- 服务器返回 404 或 5xx、而本机有副本时，提示条的文案不该写「无法连接」：404 按「活动已不存在」处理，5xx 写「服务暂时不可用，显示截至…」。
