# Sprint 0084 — 资料类页面：分组标题、可点入口、字段、静态值各归其位

## 要实现什么

编辑资料、更多资料等页面里，分组标题、可点进去的入口、字段标签、静态值长得一样，看不出主次。本 Sprint 先做一次全面截图审核（逐页标出四类元素现状），出设计案获批后，改共用组件 `ProfilePagePrimitives` 及同类结构页面。

## 做完能看到什么

- 一份审核清单：每个页面的截图 + 四类元素标注 + 问题点。
- 一份设计案（artifact）：四类元素的统一规格（字号／字重／颜色／间距／可点提示）。
- 获批后：6 个资料页与审核中列出的其它页面按规格改完，phoneweb 与 Simulator 截图前后对照。
