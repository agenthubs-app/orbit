# Sprint 0028 — “我的”页面组新版设计

## 要实现什么

把“我的”、设置、账号与工作区以及完整的资料编辑流程实现为用户最新提供的 Ink & Signal 设计，同时继续读取和保存真实账号资料，不把设计稿示例、无效按钮或仅截图外观当成功能。

## 做完能看到什么

- “我的”按新版显示头像、姓名、真实统计、基本资料、“我能帮／我想找”标签和账号入口；设置与账号页沿用同一视觉语言，已有通知、语言、权限、服务器和退出能力仍可用。
- 点“编辑资料”进入独立编辑页；姓名、职位、公司、“现在在做”、标签、联系方式、更多资料、名片／简历建议均能在多级页面间保留草稿，并通过一次有版本保护的保存写回。
- “资料建议”支持逐条采用、忽略和编辑后采用；“他人看到的样子”严格排除生日、默认跟进节奏等仅本人字段，并且不把预览按钮误当成对自己的真实社交操作。
- 加载、空资料、失败、保存冲突、导入失败、大字号和中／日／英状态均有明确可恢复结果；所有可操作控件可点击且至少 44pt。

## 怎么验收

先用失败测试锁定八屏路由、资料字段转换、草稿连续性、建议决策、版本冲突和隐私投影，再做定向 GREEN。随后用当前源码重新构建并启动 Web/API，令 Web 浏览器与 iOS Simulator 使用同一脱敏账号和数据库，完成 Web→App 与 App→Web 的同一资料回读；逐屏对照本 Sprint 保存的 390×844 设计图，并检查大字号、键盘、返回、错误恢复和另一账号隔离。
