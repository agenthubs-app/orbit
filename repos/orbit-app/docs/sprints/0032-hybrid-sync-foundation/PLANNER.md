# Sprint 0032 Hybrid Sync Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish a secure, actor-isolated local entity mirror and shared sync contract while preserving server authority and all current screen behavior.

**Architecture:** Add a generated cross-client sync contract, encrypted SQLite schema, scoped repository and lifecycle coordinator. Keep legacy path snapshots active until Sprint 0033; no product screen may claim offline mutation support in this Sprint.

**Tech Stack:** TypeScript, Expo 57, expo-sqlite/SQLCipher, expo-secure-store, Zod, Node test runner, Xcode/iOS Simulator, existing contract sync.

**Spec:** `repos/orbit-app/docs/sprints/0032-hybrid-sync-foundation/DESIGN.md`

## Global Constraints

- **原需求：** 用户批准“云端权威、部分本地持久化、不是每次都全量上传下载”的分阶段方案。
- **基线：** 计划编制基线 `chat-agent@549ed3521d77ba2472dced6efed5379ca6ca495d`；run-01 必须使用已合并 Sprint 0031 的更新主线 SHA 并记录，不能与 0031 并行修改 `snapshot-store.ts`、`useApiResource.ts` 或 App 构建配置。
- **进入条件：** 0031 完成或明确释放重叠文件；ADR-0006 与本 Planner 已批准；原生重新构建权限和可用 iOS Simulator；不得要求真实业务数据迁移。
- 单个 Generator 执行。运行前为每个待改既有符号做 GitNexus upstream impact；HIGH/CRITICAL 先报告并扩展定向回归。
- 只把服务端确认 revision 当作 canonical；本地时钟、SQLite rowid、路径快照和 AI 上下文均不得成为权威版本。
- SQLCipher 初始化失败时必须 online-only，禁止静默写明文。日志不得含密钥、业务 payload 或完整 actor ID。
- 本 Sprint 不切换页面、不发送 outbox、不删除 `api_snapshots`、不部署、不修改生产数据。
- 实现完成后必须 commit，交接固定 SHA，由协调者合并到 `chat-agent` 并验证合并树；没有 merge 不得 completed。
