# Sprint 0032 — 云端权威与加密本地镜像基础

## 要实现什么

为 App 建立一套不会产生第二权威源的同步基础：服务器仍决定最终数据，手机用按账号隔离且加密的 SQLite 保存规范化记录、同步游标和待发送操作。

## 做完能看到什么

- 账号、服务器或工作区切换后，只能读取当前范围的本地数据；旧账号内容不会闪现。
- 本地数据库能明确区分“已同步、等待同步、冲突、永久失败”，并保留删除墓碑，不再只按 API 路径保存整包 JSON。
- SQLCipher 或密钥初始化失败时，App 明确退回在线模式，不把未加密个人数据写到磁盘。
- 笔记、待办、已确认跟进和个人日程从一开始就携带 AI 可见性规则；本地待同步内容不会被标成 AI 已可见。

## 怎么验收

先以纯契约测试锁定实体类别、权威级别、游标、墓碑、同步状态和 AI 可见性，再以 SQLite 集成测试验证事务、账号隔离、数据库迁移、加密开启、登出清除和损坏恢复。此 Sprint 只建立基础设施，不切换现有页面读取，也不提供离线写入成功提示。

完整范围见 [DESIGN.md](DESIGN.md) 与 [PLANNER.md](PLANNER.md)。本页不表示已经实现；状态以执行后的 `REPORT.md` 和主线合并验证为准。
