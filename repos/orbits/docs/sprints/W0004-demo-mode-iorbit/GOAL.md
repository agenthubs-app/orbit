# Sprint W0004 — iOrbit 示例模式

## 要实现什么

新用户在完成引导第 1–3 步之前，打开 iOrbit 看到一位示例人物（在东京做 AI SaaS 出海的创始人）完整的一天；想操作时被拦下并引到引导。

## 做完能看到什么

- 顶部「示例预览」横条：说明、进度、下一步和「开始／继续引导」；可收起成导航栏药丸，不能永久关闭。
- 今日要事、时间线、本周推进、已报名活动、最近对话全部有示例内容，示例人名旁有「示例」角标。
- 打勾、确认、问 iOrbit、发送等写操作弹出「这是示例，完成引导后这里会是你自己的 ___」并提供继续引导。示例数据只在前端，不写入数据库。

依赖 W0001。按 D1：功能合入但开关默认关闭，W0008 上线时打开。按 D2：已有 ≥3 位已确认联系人的老用户不进入示例。
