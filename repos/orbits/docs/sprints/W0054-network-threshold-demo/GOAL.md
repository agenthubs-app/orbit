# Sprint W0054 — 引导第 1 步满 3 张、分析门槛与示例完整快照

## 要实现什么

新用户必须放进 3 位已确认联系人才算做完引导第 1 步（不再能「先这样，继续」）；引导一旦完成就永远算完成，之后联系人少于 3 位时，只把 AI 人脉分析那几块换成「再添加 N 位联系人即可更新分析」；还在示例里的人打开人脉分析，能看到示例人物一份结构、机会、洞察三标签都有内容的静态快照。

## 做完能看到什么

- 引导页第 1 步：没有跳过按钮和「代价」说明；已确认 0～2 位时显示「已确认 x / 3」，只能继续扫名片或去导入人脉；中途离开再回来，从第 1 步接着做，期间首页、人脉、计划仍是示例。以前已经点过「先这样，继续」的老账号不被打回（见已定项 W54-1）。
- 做完引导的人把联系人删到 2 位：首页、计划、人脉列表、统计图照常；「结构」的诊断与 AI 洞察、「机会」的叙述与报告卡、「洞察」标签、联系人详情顶部「和你目标的关系」不再显示旧快照，换成一张「再添加 1 位联系人即可更新分析」卡和「扫名片」按钮；补回到 3 位后按 RN-06 自动重算。引导不重新出现，示例不回来。
- 示例期打开 `/app/contacts/dashboard?tab=structure|opportunities|insight`：三个标签都有示例人物的内容，名字和快照旁有「示例」角标；「示例里没有 AI 人脉分析」那页消失。整个过程不写库、不请求任何真实分析或 AI 接口。

## 怎么验收

测试证明四条边界：第 1 步不能再跳过且存量跳过的人按 W54-1 处理；完成状态不因删联系人、计划到期而回退；不足 3 人时旧快照的文字不进入页面数据、不触发 AI 重算；示例期对真实分析／AI 接口 0 调用、0 写入。再在 3001 验收环境用 `verify-new`、`verify-plan` 走一遍，桌面 1440 和手机 375 各截图，并做一次全量对照与一次 Codex 代码 review。
