# Sprint W0015 — 活动归属询问

## 要实现什么

用户报名了某个活动，在活动当天或次日扫的名片，审阅时会被问「这些是在 X 活动认识的吗？」，确认后联系人记上来源活动，计划里该活动标为已参加。

## 做完能看到什么

- 审阅页顶部出现活动归属询问，默认勾选，可取消。
- 确认后联系人来源写为该活动；本人生效计划中对应活动项变为「已参加」并写进展记录；与该活动关联的人脉需求在匹配时优先。
- 没有报名活动或不在时间窗口内时不出现询问。
