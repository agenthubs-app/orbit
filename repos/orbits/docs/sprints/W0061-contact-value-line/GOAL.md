# Sprint W0061 — 「TA 能帮你」一句话，在首页、导入后和详情里说同一句

## 要实现什么

做一个共用的「价值一句话」：**TA 能帮你：{和你目标的关系} · 依据：{名片／memo／计划需求}**。它出现在三个地方，说法完全一致：

1. 首页「今日要事」里指向某个人的事项（例如「请陈思远引荐一家被投公司」）；
2. 扫完名片后「N 位新联系人可能对应你的计划」的候选卡；
3. 联系人详情「为什么是 TA」的第一行。

找 TA 引荐、找 TA 聊一聊这类事项，再多一行「为什么现在：…」，理由取计划里这一条自己的阶段、需求和缺口（没有才用洞察给的下一步）。**不新增任何 AI 调用**，只读已经生成好的内容。

## 做完能看到什么

- 首页今日要事的人物卡：一句「TA 能帮你：…」、依据小签，计划行动多一行「为什么现在：计划第 2 周『拿到 3 个引荐』还差 2 个」。
- 导入后的候选卡：每人一句「TA 能帮你」，下面是「对应：{计划需求}」和依据（名片职位／行业规则匹配）。
- 洞察还没生成好时不会空白：显示「公司 · 职位」+ 可能对应的需求 +「生成中」，生成好后自动换成正式的一句。

## 怎么验收

- 测试：同一组件在三处的输出一致；没生成时的退化显示；「为什么现在」的取值顺序；读取路径 0 次模型调用；他人联系人读不到。
- 实测：新增读取的数据库字节按 D39 口径记进流量表。
- 真实页面：三处在桌面 1440 和手机 375 各看一次。
