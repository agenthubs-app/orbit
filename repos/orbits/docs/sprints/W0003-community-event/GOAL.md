# Sprint W0003 — iOrbit 社群卡片

## 要实现什么

活动页最上面永远有一张免费的「加入 iOrbit 用户社群」卡片，用户扫码加助手进群后点「我已加入」，之后在 iOrbit 的已报名活动里看到「已加入社群」；活动推荐理由只写真实匹配到的目标词。

## 做完能看到什么

- 活动页顶部固定显示社群卡片（免费 · 长期有效），卡片里有二维码、微信号和群介绍（素材到位前是明确标注的占位），微信号可复制。
- 点「我已加入」后卡片变成「已加入」，iOrbit 底部「已报名活动」栏出现「已加入社群」；换设备登录仍是已加入。
- 推荐活动的理由写成「匹配你的目标：『开拓新市场』『日本』」，不再出现编造的数据。社群不是活动，不改活动数据和报名规则。

## 怎么验收

加入记录接口的路由测试（登录、只改本人、重复点击幂等）；活动页与 iOrbit 的组件测试；浏览器在活动页点一次「我已加入」并刷新回读。

完整验收项和启动条件见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；当前状态见[登记表](../README.md#sprint-登记表)，实际执行结束后再记录报告。
