# Sprint W0059 — 关掉联系人详情，回到你刚才所在的页面

## 要实现什么

从首页、计划、人脉分析、活动等任何地方点开一位联系人，关掉详情时回到**原来那一页、原来的滚动位置**，而不是一律跳回「所有人脉」。只有直接打开链接（比如从书签或别的网站进来、没有站内来路）时，才回到「所有人脉」。右上角 ×、底部「关闭」、按 Esc、点弹窗外面，四种关法结果完全一样。

## 做完能看到什么

- 在首页今日要事点「打开联系人」→ 关掉 → 回到首页，还在原来滚到的位置。
- 在人脉列表滚到第 3 屏点开一个人 → 关掉 → 回到列表第 3 屏。
- 复制详情链接到新标签页打开 → 关掉 → 到「所有人脉」。
- 详情左上角有「返回 {来源}」（例如「返回 iOrbit」「返回人脉」），和关闭同一行为；示例模式里的示例详情照旧只收起弹窗、不跳转。

## 怎么验收

- 测试：有站内来路时四种关法都走「后退」；没有来路时都去「所有人脉」；带 `returnTo` 时只接受站内路径；示例弹窗不导航；在输入框里按 Esc 不关。
- 真实页面：首页、计划页、人脉列表、人脉分析各点开一次再关，确认回到原页原位置（桌面 1440、手机 375）。
