# Sprint W0008 — 生成第一份计划

## 要实现什么

用户问一次固定问题，几秒内先看到结论和阶段骨架，随后阶段细节逐个补齐，最后自动保存为「我的计划 v1」。

## 做完能看到什么

- 回答结论在前：一句话回答、3 个关键数字、三个阶段、这周 3 件事、现有人脉能帮什么、最大风险、30 秒自我介绍、阶段细节折叠。
- 计划里提到的联系人和活动都是真实存在的，校验器拒绝编造的 id。
- 周期按目标期限切分；一年期只细化第一阶段。

## 前置

依赖 W0006、W0007。按 D3 决定：本 Sprint 先不接 AI，计划内容来自 mock 数据，但「生成中（先出结论和阶段骨架，细节逐个补齐）→ 已完成」的过渡完整做出来；生成通道留好接口，接 AI 另开 Sprint。
