# Sprint W0024 — 活动页按账号 id 读报名

## 要实现什么

已登录用户打开活动页 `/app/events`，「已报名」标记和「已报名」筛选按账号 id 读报名，跟报名接口写入时用的 id 一致（与 W0018 修的 iOrbit 首页同一口径）。账号 id 与登录会话 id 不同时，报过名的活动不再显示成未报名。

## 做完能看到什么

- 报名记在账号 id 下：活动页显示「已报名」，「已报名」筛选里能看到。只记在会话 id 下的旧数据不算。
- 查询次数不增加：账号只解析一次，而且仍在活动目录读取成功之后才解析；报名读取和社群状态共用这个结果。目录读取失败时不读账号。
- 返回字节会变：原来用会话 id 查不到的报名行，现在会真实返回。这个增量要实测或估算，并在上限之内（1000 人每月 ≤30 MB）。
- 未登录时的活动页、社群卡片、活动顺序都和现在一样。

## 怎么验收

- 页面测试分别造出 legacy 投影和 canonical 报名两条路径，证明只按账号 id 读；计数账号解析、报名读取各 1 次；目录失败时账号解析 0 次。
- 账号解析失败时页面不报错、不改用会话 id。
- 本机测量报名读取的返回字节，按假设估算月增量写进 REPORT。
- 3001 验收 server 上用 verify-plan 看活动页（桌面 1440、手机 375），确认没有回归。
