# Sprint W0043 — 人脉页不出调试英文，空态说实话

## 要实现什么

人脉概览、AI 人脉分析（结构／机会）、关系管线和分组详情页上，用户不再看到后端调试英文（如「X added to the live relationship database」「Rule-based summary of the live dashboard aggregate.」），后端返回「空」时显示对应的真实空态，只有接口失败才显示「来源暂时不可用」；所有面向用户的文字中英双语。

## 做完能看到什么

- 只有 9 位联系人、没有缺口的账号打开「机会」标签，看到「暂无覆盖缺口」这类真实空态，而不是「来源暂时不可用」；接口真的失败时才出现「来源暂时不可用」。
- 中文和英文界面里，结构诊断、分布小结、缺口、建议动作、待唤醒、最近动态都不出现调试英文；没有真实内容的句子不显示，不用占位句凑数。
- 系统分组名（未分类、地区待完善、经营决策者、强关系等）在英文界面显示英文；最近动态显示「新增联系人 · 王敏」这类由真实数据拼出的双语文字。

## 怎么验收

用含全部已知调试句的后端返回夹具渲染各页面（中、英各一次），测试断言调试句一句都不出现；分别给出「每个分区 empty」「分区读取失败」两组夹具，断言空态与「不可用」各在其位。本机真实账号在 1440 与 375 下截图，并用页面文本检索确认无调试句。后端、`shared/compute` 与手机接口不改。
