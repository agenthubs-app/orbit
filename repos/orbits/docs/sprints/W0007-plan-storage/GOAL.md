# Sprint W0007 — 计划的结构化存储

## 要实现什么

计划能按阶段、行动、人脉需求、要获得的信息和活动结构化地保存、更新和版本化。

## 做完能看到什么

- 新增 plans、plan_items、plan_log 三张表及仓储与 API；同一时间只有一份生效计划。
- 行动、人脉需求、信息、活动四类对象可以单独改状态、关联联系人或活动、填答案；每次变化写进展记录。
- 重新分析生成新版本时继承已完成内容，旧版本保留。
