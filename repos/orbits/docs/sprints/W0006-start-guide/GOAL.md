# Sprint W0006 — 独立引导页 /app/start

## 要实现什么

新用户在 /app/start 按顺序完成名片、目标、计划三步（活动随时可做），中途离开、换设备回来都能从原处继续。

## 做完能看到什么

- 步骤条标明已完成、进行中和锁定；第 1–3 步严格按顺序解锁，第 4 步随时可点。
- 第 1 步显示「已确认 x / 3」并可带说明地跳过；第 2 步用 W0002 的编辑器，onboarding 已有目标则自动完成；第 3 步问前可就地改目标。
- 第 4 步社群卡片置顶（复用 W0003）；前 3 步完成后 iOrbit、人脉、计划同时换成用户自己的数据。

## 前置

依赖 W0002、W0003、W0004。按 D1 开关默认关闭；按 D2 老用户（≥3 位已确认联系人）第 1、2 步视为完成。

完整验收项和启动条件见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；当前状态见[登记表](../README.md#sprint-登记表)，实际执行结束后再记录报告。
