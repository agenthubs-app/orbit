# Sprint W0058 — 名片确认后推测「TA 能给你的／TA 需要的／可以聊的话题」

## 要实现什么

名片确认后，Orbit 在**已经要做的那次 AI 生成里**（W0057 的即时洞察生成，同一次调用，不多花一次），顺带根据对方的公司、职位、部门和名片备注，推测 TA 能给你什么、TA 可能需要什么、可以聊哪些话题，写进联系人资料并标明「据名片推测」。之后你写了 memo，AI 从 memo 里整理出的内容会替换推测；你自己改过的永远不被覆盖。

## 做完能看到什么

- 新扫的联系人，详情里「TA 能给你的／TA 需要的／可以聊的话题」不再是空的，推测出来的每一条都带来源，界面上浅色显示并有「据名片推测」角标（显示样式在 W0060 落地）。
- 推不出来就留空：只写名片上看得出依据的内容（例如「投资总监」→「融资判断与被投公司资源」），空洞套话（「人脉资源」「合作机会」之类）一律被拒。
- 写 memo 后 AI 整理出的「能给／需要／话题」会替换推测值；手动改过的字段不会再被推测改写。

## 怎么验收

- 测试：同一次调用同时产出洞察和三栏推测；推测值来源标为「据名片推测」；memo 整理与用户手改的值不被推测覆盖、推测值会被 memo 整理覆盖；输出校验拒绝空洞套话和无依据的条目；无目标时不调用模型；名片备注里的邮箱电话不进提示词。
- 用 mock 生成器在本机走一遍「扫名片 → 确认 → 详情三栏有推测值」；是否做真实 DeepSeek 演练待用户决定。
