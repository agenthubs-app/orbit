# Sprint W0010 — 人脉需求匹配

## 要实现什么

用户扫进名片后，系统提示其中谁可能填上计划里需要的某类人；确认后本周多一条「约 TA」行动。

## 做完能看到什么

- 名片批次确认后补全行业并匹配；审阅页最后一屏最多等 8 秒给出候选，晚到的结果出现在今日要事和计划页角标。
- 匹配永远需要用户确认；关联后生成带「定时间／起草邮件／记一次互动」的行动。
- 活动归属询问不在本 Sprint，见 W0015。

## 前置

依赖 W0007、W0009、W0013（识别时补好的行业）。第二轮按公司、职位的 AI 匹配沿用名片识别的计费方式。

完整验收项和启动条件见 [PLANNER.md](PLANNER.md)。本页说明预期目标，不代表已实现；当前状态见[登记表](../README.md#sprint-登记表)，实际执行结束后再记录报告。
