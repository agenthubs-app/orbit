# Sprint W0038 — 月历两色圆点与「下一场活动」

## 要实现什么

用户在 iOrbit 首页右栏的月历上，一眼分清自己已经定下的安排和值得去的推荐活动。今天没有日程时，日程区会告诉他下一场活动是哪天、叫什么。

## 做完能看到什么

- 有日程、约谈或已报名活动的日期，下面是实心靛蓝点。推荐活动（和今日要事小模组用的是同一批，当月最多 5 场）是空心浅色圈。同一天两种都有时，两个点并排。月历下方有一行小图例。
- 圆点本身不可点：点某个日期选中这一天，右栏列出当天的全部安排，推荐活动也在里面。点时间线里的推荐活动进活动详情，点日程进对应的日程页，点已报名活动进活动详情。
- 今天没有日程时，原来的「今天没有已确认的日程」改成「下一场活动：10/3 周五 <标题>」。已报名的活动优先（最早一场），没有就用推荐活动池里最早开始的一场，点它进详情。
- 示例首页的月历也画真实推荐活动的空心圈。
- 暖色 #C4461B 只标时效，圆点和图例不用它。

## 怎么验收

- 组件测试覆盖：圆点的种类和上限、同日并排、东京日期的跨月边界、推荐活动不会混进今日要事和日程计数、每种条目的跳转地址、「下一场活动」的取数顺序。
- 每个日期按钮的读屏标签里都写明当天有几项日程、几场推荐活动。
- 跑 typecheck 和 ratchet，在 3001 验收环境用桌面 1440 和手机 375 各看一次。
- 档位 H（首页组件 `IOrbitHome` 在影响分析里是 CRITICAL）：一次 Codex 代码 review、一次全量测试对照基线。
