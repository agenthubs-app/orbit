# Sprint W0005 — 人脉页示例模式

## 要实现什么

新用户打开人脉页，看到示例人物的 30 位联系人、关系管线和详情，扫名片仍是真实操作。

## 做完能看到什么

- 概览、关系管线、所有人脉三个标签页都有示例数据；点任何人打开详情弹窗，其中 8 位有完整互动与需求。
- 记录互动、更新状态等写操作被拦截；「扫描名片」「导入人脉」照常可用并计入引导第 1 步。
- 完成引导第 1–3 步后，人脉页只显示用户自己的联系人。
