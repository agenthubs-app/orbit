# Sprint W0022 — 老用户首页引导入口与策略页

## 要实现什么

老用户（有联系人和目标、还没有计划）在 iOrbit 首页点「帮我制定推进计划 →」，直接进入引导第 3 步生成计划。计划做好后，只要第 4 步（活动／社群）还没做，首页会留一条提醒。策略页「先联系谁」不再无故显示「来源暂时不可用」。活动推荐理由（RW-07）在验收数据下能在页面上看到。

## 做完能看到什么

- 开关打开时，没有计划的老用户点「帮我制定推进计划 →」，落在 `/app/start` 第 3 步。开关关闭时，这个链接和现在一样。
- 有了计划、但没加入社群也没报名任何活动时，首页「已报名活动」栏首有一行提醒，链接到引导第 4 步。加入社群或报名任一活动后，提醒消失。
- 本机验收 server 上，策略页「先联系谁」显示真实的跟进联系人；没有跟进时显示「当前没有待推进的联系人机会」，不再显示「来源暂时不可用」。
- 用验收种子造出的数据，在策略页「下一步去哪」能看到「匹配你的目标：『…』」和「对应你计划第 n 阶段：…」两种理由。

## 怎么验收

- 组件测试和纯函数测试覆盖三类：链接指向（开关开和关）、`?step=3` 不能绕过硬顺序、提醒的出现和消失条件。
- 用 PG 差分测试证明：新加入白名单的本机运行时与旧排序结果一致；不在白名单里的运行时仍然拒绝读取。
- 在 3001 验收 server 上，用 verify-legacy、verify-plan 等账号，桌面 1440 和手机 375 各走一遍首页、引导页和策略页。在 3000（开关关闭）确认首页不变。
