# Sprint W0022 — 老用户首页引导入口与第 4 步提醒

## 要实现什么

老用户（有联系人和目标、还没有计划）在 iOrbit 首页点「帮我制定推进计划 →」，直接进入引导第 3 步生成计划。计划做好后，只要第 4 步（活动／社群）还没做，首页会留一条提醒，点它进入引导第 4 步。

## 做完能看到什么

- 开关打开时，没有计划的老用户点「帮我制定推进计划 →」，落在 `/app/start` 第 3 步；开关关闭时，这个链接和现在一样（`/app/agent/strategy`）。
- `/app/start?step=3`、`?step=4` 只在该步已经可以打开时生效；步骤锁着或参数非法时，按原来的逻辑显示第一个未完成的步骤，不能绕过硬顺序。
- 有了计划、但没加入社群也没报名任何活动时，首页「已报名活动」栏首有一行提醒，链接到 `/app/start?step=4`。加入社群或报名任一活动后，提醒消失。读不到报名状态时不显示提醒。

## 怎么验收

- 组件测试和纯函数测试覆盖：链接指向（开关开和关）、`?step` 不能绕过硬顺序、提醒的出现和消失条件、读取失败时不显示。
- 页面测试计数新增读取：开关关闭、示例期、已加入社群时新增 0 次。
- 在 3001 验收 server 上用 verify-legacy 走一遍「首页 → 第 3 步 → 生成计划 → 首页提醒 → 第 4 步」，桌面 1440 和手机 375 各一次；在 3000（开关关闭）确认首页不变。
