# Sprint W0014 — 我的计划与示例对话的示例模式

## 要实现什么

引导期间用户打开「我的计划」或从最近对话进入示例问答，看到示例人物的 12 周计划和一段结论在前的示例回答，所有写操作被拦截。

## 做完能看到什么

- 「我的计划」页在示例期间显示示例计划（本周、阶段、人脉需求、进展记录），带横条与示例角标。
- 最近对话里的示例问答打开后是 W0008 同款计划卡片，内容来自示例数据；追问输入框在示例期间被拦截。
- 示例期间计划页与对话页都不发出真实读取或写入请求。

## 前置

依赖 W0004（示例骨架）、W0008（计划卡片组件）、W0009（我的计划页）。
