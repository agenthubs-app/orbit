# Sprint W0026 — 推荐理由的验收数据与页面复验

## 要实现什么

验收种子造出真实可匹配的活动，让策略页「下一步去哪」的两种推荐理由——「匹配你的目标：『…』」和「对应你计划第 n 阶段：…」——能在 3001 验收 server 上被看到和复验。只改验收数据，不改分词和推荐算法。

## 做完能看到什么

- verify-legacy（有目标、没有计划）打开策略页，「下一步去哪」出现一场验收活动，理由是「匹配你的目标：『…』」，引号里的词确实出现在活动文字里。
- verify-plan（有计划）打开策略页，计划里挂着的那场验收活动显示「对应你计划第 n 阶段：…」。
- 重置种子两次结果一致；非验收数据的指纹前后一致；W0018 各场景原有的数据不被破坏。

## 怎么验收

- 运行种子脚本（`--reset` 连续两次、`--fingerprint`），数据库读回新活动和计划条目。
- 3001 上两个账号各看策略页，桌面 1440、手机 375 各一次。
- 中文目标分词的问题（整句成词、数字成词）只登记，不在本 Sprint 修。

完整验收项见 [PLANNER.md](PLANNER.md)。本页只说明预期目标，不代表已实现；当前状态见[登记表](../README.md#sprint-登记表)。
