# Sprint W0035 — 引导改为 3 步

## 要实现什么

引导页 `/app/start` 只剩 ①名片 ②目标 ③生成计划 三步。做完第 3 步就是全部完成；原来的第 4 步「活动」从引导页、进度判定、首页提醒和相关文案里移除。已经停在第 4 步的老用户照常打开引导页，不会卡住或报错。

## 做完能看到什么

- 引导页的步骤条、手机上的进度线、「第 n 步 / 共 3 步」、标题和完成卡片都按 3 步显示；完成卡片不再有「做第 4 步」，步骤条旁不再有「先看活动 →」；`/app/start?step=4` 被当成非法参数忽略。
- 首页「已报名活动」栏首不再出现「引导第 4 步：加入社群或报名一场活动 →」；首页服务端不再为这条提醒读报名事实。社群行、「看看推荐 →」暂时保留，由 W0037 换成活动小模组（见 PLANNER 的 W35-2 说明）。
- 引导记录里存着 `currentStep = 4` 的人打开引导页时，按进度落在第一个没完成的步骤或完成卡片；示例模式的结束条件、`completedAt` 的写入时机都不变；社群加入记录和报名数据原样保留。

## 怎么验收

- 纯函数和引导记录测试：只有 1–3 步、`?step=4` 被忽略、存量 `currentStep = 4` 读成「没有记录」、再写 4 被拒绝且记录不变、`completedAt` 仍然只在前 3 步完成时写一次。
- 页面测试：引导页和首页在开关打开、关闭、示例期三种情况下都不再读第 4 步用的数据；首页其余栏目与改动前一致。
- 在 3001 验收 server 上看新用户、停在第 4 步的老用户和已有计划的老用户三种页面，桌面 1440 和手机 375 各一次；在 3000（开关关闭）确认首页不变。档位按 H 收口：一次全量对照基线和一次 Codex 代码 review。
