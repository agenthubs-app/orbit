# Sprint W0052 — 人脉概览：驾驶舱读快照，管线改档位，动态来自时间线

## 要实现什么

用户打开人脉概览（`/app/contacts/dashboard`），「AI 人脉驾驶舱」4 张卡显示快照里的一句话判断和按规则算出的关键数字；「关系推进管线」改成按 新认识／有往来／核心／待唤醒 四档显示人数；「最近动态」来自关系时间线（memo、见面、计划、日程、跟进、扫名片），中英双语。

## 做完能看到什么

- 驾驶舱：例如「结构」卡写着快照的诊断句和「35 位联系人」，「目标缺口」卡写着缺口叙述和「已有 3／共 8」，点卡片进对应标签；没有快照时只显示数字，不放占位句；没有计划时缺口卡给「生成计划」入口。
- 管线区：四档人数之和等于全部联系人数（不是名单前 30 位），不再出现「待了解／推进中」这类手动阶段；点档位进入按档位分组的关系管线页。
- 最近动态：最新 5 条互动，每条有联系人姓名、来源（memo／活动／计划…）和时间；不再出现「added to the live relationship database」。

## 怎么验收

组件与模型测试覆盖：快照有／无／读失败；有计划／无计划；35 人夹具验证全量人数；时间线夹具覆盖每种来源与双语；示例期概览照常。打开概览对付费 AI 0 调用。新增数据库读取按 D39 口径实测估算。本机真实账号 1440／375、中英截图。
