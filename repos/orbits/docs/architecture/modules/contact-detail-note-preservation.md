# 联系人详情写入保留既有记录

2026-09-08 修复：`live-detail-service` 原先只把 `note:live-contact-detail-update:*` 写回详情状态。标签、状态、最近互动或新记录写入时，会丢弃同一 actor 已保存的活动交流／会后记录；手动记录的 `privacy` 和 `sourceLabel` 也会丢失。

内部读取现在同时保留原始详情状态和公开结果。写回时保留原存储中的记录 ID，以及本次手动记录，完整携带隐私与来源字段；从关系证据临时派生的时间线不重复持久化。内部原始状态不会添加到公开响应中，不新增数据库查询或共享契约字段。

真实内存存储回归连续执行标签、互动、状态、新记录和同记录重试，验证私人交流、双方纪要、旧手动记录都保留，新记录不重复，重新创建服务后仍可读。另有详情路由与服务回归。没有访问业务数据库，也未尝试恢复已在历史写入中丢失的数据。

这项修复不提供跨请求事务或版本锁定；同一详情状态的并发写协调仍沿用现有 provider 能力。
