### Agent worker 临时故障恢复（2026-09-06）

`npm run agent:worker` 在单轮数据库或服务失败后使用最高 30 秒的指数退避，成功后恢复正常轮询。并行 outbox、定时自动化与信号任务必须全部结束才允许下一轮开始，防止失败任务提前返回造成并发轮询重叠。SIGTERM / SIGINT 停止接新任务、等待本轮结束，并立即打断空闲等待；错误日志不输出 provider 原始响应。

验证：`tests/services/agent-worker-recovery.test.ts` 覆盖临时故障后恢复、退避上限和成功后重置、并行任务失败时等待其他任务、停机排空；`abortable-worker-wait.test.ts` 验证打断等待。此处证明常驻 worker 的控制流程，不代表它已部署，也不替代真实数据库租约重启测试。Vercel Preview 不运行原生 cron，仍需独立运行环境或调度来源；部署验收未完成。
