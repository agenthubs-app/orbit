### 2026-09-06：已确认 Agent 操作接入 Vercel 队列

Vercel live 模式下，运行时工厂对确认和显式重试增加持久化队列发布；发布接受后才完成该方法。队列只包含服务器取得的 actor / run / action 标识与版本，不包含操作正文或凭证。发布失败返回固定错误，数据库中的操作保留，可重新确认；已完成操作的重放不再发布。消息保存 7 天，不按 action ID 使用 SDK 的 24 小时去重，以免终止失败后的显式重试被吞掉。
