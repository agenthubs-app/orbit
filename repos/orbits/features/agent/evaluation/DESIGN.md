# Agent 功能验收报告

`/dev/agent-test-report` 是 Agent 的可执行验收说明，而不是营销页面。

报告遵循三个约束：

1. 能力清单直接读取 `features/agent/capabilities/registry.ts`，防止实现和说明漂移。
2. 每个实验同时记录实验方法、成熟产品预期、真实结果和证据来源。
3. 真实账户实验只用于读取链路；写操作、并发、失败和外部权限使用确定性自动化验证，避免测试污染账户或外部系统。

本轮真实账户基线：

- 公开活动目录有 13 个活动，其中 2 个尚未开始。
- 测试账户有 12 位联系人、12 条关系和 48 条关系证据。
- 测试账户没有独立 `TaskDTO`，但每条关系有可复核的建议行动。

跟进队列会同时读取已创建任务和未被任务覆盖的关系建议。后者在结果中保持为 `relationship-suggestion:*` 的只读候选，来源类型为 `system`，不会写入任务、提醒、日历或外部系统。
